# Project Design
**Status:** APPROVED
**Revision:** 1
**Product Authority:** PRODUCT.md revision 1

## Visual North Star
A quiet, warm, left-aligned reading guide. The title and readable guidance lead; the reference collection is supporting context. Keep the light canvas, dark ink, restrained blue action and plain editorial content.

## Typography
No exact family, type-role map, size scale, weight palette or line-height system has been approved. The current mixed type treatments are defects, not authority. A restrained local system-family treatment is within this direction. Do not download fonts or introduce a new decorative brand identity.

## Composition / Spatial Hierarchy
Preserve the page purpose → preparation → handover sequence and the reference collection's secondary role. Keep the existing six-role spatial profile and overall content layout. Reading-column measure and text-block fit may change as part of typography refinement, but no page-wide spacing-system redesign is requested.

## Responsive Translation
Keep a legible single-column reading guide, all semantic content and the action. Current numerical font shrinking is not approved. Re-evaluate wrapping and reading comfort at the actual mobile viewport.

## Approved Visual Evidence
The fixture owner accepts the direction described above, not the deliberately inconsistent initial typography. No exact refined render is accepted yet.

## Amendment Rule
This is bounded refinement within APPROVED Rev 1. Internal conformance does not create user acceptance or promote a new direction.
