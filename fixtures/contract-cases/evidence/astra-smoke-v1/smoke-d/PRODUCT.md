# Northbank Product Authority
Status: APPROVED. Revision: 1.

Northbank is a static reading guide for the volunteers who host a community learning room. The current reader is a host preparing for a shift. The populated reading-guide state is the only scope.

Primary purpose and priority: understand the hosting guidance, then read the handover guidance. Page title: Make every handover easy to follow. Lead: A practical reading guide for hosts before, during, and after a shared session.
The only primary action is Read handover, a native in-page link to #handover. It does not create or submit anything.

The side reference collection is secondary context, not a dashboard or performance measure. Its count is exactly 12, labeled Reference notes. It must not displace the guide title or reading task as the primary focal point. Decorative circle artwork has no product meaning.

Content structure and roles:
- Two peer guide sections: A, Before the room opens; B, A useful handover.
- Each section contains an introductory reading paragraph, a subsection heading, two long reading paragraphs, and a set of three short reminders.
- The two section titles have the same semantic type job. The two subsection titles have the same semantic type job. All long reading paragraphs have the same body-reading job across A/B.
- All six reminder titles have the same reminder-heading job; their order does not create separate title roles. Reminder descriptions are short supporting body text.
- The reference collection title is supporting context even though its markup is h2, like the peer guide section titles. Visual importance must follow this Product priority, not heading tag alone.
- Keep the current valid semantic heading levels/order and all exact text in index.html; do not rename, summarize, add or remove copy for visual convenience. Additional implementation wrappers carry no product meaning.
- Owner and revision lines are supporting metadata, not prominent reading content.
- Preserve all required content and the same native anchor action on mobile. No extra routes, controls, statuses, permissions, actions, integrations or editorial claims are authorized.

The exact frozen index.html is the canonical content payload under this authority. Footer: Local reading guide · Example content. This is neutral fictional example content, not guidance for a real operation.
