Preparation

Before the room opens

A useful session begins with a shared picture of the room and the people who will use it. Give yourself time to read the host note before anyone arrives. The note is a starting point for a conversation, not a script that every person must follow in exactly the same way.

Welcome people with useful context

Begin by describing what is available in the room and how the session will unfold. People arrive with different levels of familiarity, so explain ordinary details without assuming that everyone already knows the space. A clear introduction lets a new participant find the materials, understand when discussion begins, and see who can answer a question. Keep that introduction calm and specific. The aim is to make the shared setting understandable, not to fill every moment with instructions or to make the host the center of attention.

When you introduce an activity, connect the immediate step to the purpose of the session. Give the group a moment to read or look around before moving on. If a detail changes, describe the change in plain language and make sure the next host can find the same explanation. Consistent context helps people participate without having to reconstruct the plan from separate remarks. The host note should support that continuity while leaving room for the group to ask questions and contribute its own examples.

Continuity

A useful handover

A handover should help the next host understand what happened without replaying the whole session. Keep the summary close to the work itself: what the group discussed, which materials it used, and which questions remain open. Distinguish a useful observation from an assumption about what another person meant.

Leave a clear trail for the next host

Write the summary while the conversation is still easy to recall. Use complete sentences for the points that need context, and keep separate topics in separate paragraphs. The next host should be able to find the main thread before looking at supporting detail. A concise note does not have to be abrupt. Explain enough of the setting that a reader who was not present can understand why a question matters and what the group expected to return to later.

Before leaving, read the note once from the next host's perspective. Check whether an unfamiliar reader could tell the difference between a finished discussion and an open question. Keep references near the relevant explanation so that the reader does not have to search through unrelated material. A handover is most useful when it preserves the meaning of the session and gives the next person a dependable place to begin, without turning every small observation into a new task or promise.

Preserve the main thread

Put the central discussion before supporting observations.

Separate open questions

Describe what remains unclear without inventing a resolution.

Keep references nearby

Place each reference beside the explanation it supports.
