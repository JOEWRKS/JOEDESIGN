# JOEDESIGN Harness 채택 판단 — 2026-09-30

결정: **현재 설치된 Harness를 유지하고 관계 진단·의존성 검사 확장안을 채택하지 않는다.**
사용자가 요구한 우선순위는 디자인 완성도이며, 새 규칙의 존재나 토큰 수 차이는
실제 결과의 품질 이득을 대체하지 못한다. 현재 저장소의 Harness 소스는 설치된
기존판의 런타임 파일과 일치하도록 정리한다. 이 결정은 `joedesign` 코어, JOENESS,
JOEFLOW 또는 사용자의 디자인 작업물을 변경하지 않는다.

| 비교 축 | 기존 설치판 A | 미채택 개선안 B | 판단 |
|---|---|---|---|
| 결함 발견·수리 | 별도 결함 과제 5/5, 파일 수정 과제 6/6 | 동일하게 5/5, 6/6 | 고유 효과 없음 |
| 실제 조작 | 데스크톱·모바일 포인터 드래그, 역회전, 끝값, 초기화 동작 | 동일 동작 | 우열 근거 없음 |
| 시각 마감 | 모바일 조작부 정돈 | 데스크톱 제품 사진이 조금 크지만 모바일 문구·RESET 아이콘 줄바꿈 | 혼합 결과, B 우위 아님 |
| 검증 태도 | 브라우저 미실행 항목을 UNVERIFIED로 남김 | 동일 | 우열 근거 없음 |
| 추가 기능 | 별도 수치 관계 진단 없음 | `inspect-relations`와 선언된 의존성 검사 | 존재는 확인, 디자인 이득은 미입증 |

두 실행은 각각 제한된 과제 1회다. 전체 디자인 능력의 동등성이나 기존판의
일반적 우월성을 증명하지 않는다. 사용자 미감 평가도 수집되지 않았다. 따라서
검증되지 않은 확장을 설치본으로 승격하지 않는다. 비교 리포트는
[결함 과제](comparisons/defect-probe-20260929.md)와
[실제 파일 수정 과제](comparisons/production-probe-20260929.md)에 보존했다.
리포트가 참조하는 전체 이벤트·화면·HTML 원본은 각각 로컬
`D:\JOEWRKS\joedesign-defect-probe-20260929`와
`D:\JOEWRKS\pebble-production-probe-20260929`에 있다. 이 커밋에는 비교
리포트만 포함하므로 저장소만으로 원본 브라우저 증거를 재실행하거나 독립
인증할 수 없다.

설치판에는 이전의 시각 제작 보완이 이미 들어 있다. 그 보완은 주된 시각
위험을 먼저 시험하고, 전체 화면 품질과 모션 시퀀스를 별도로 검토하며,
정확한 사용자 거절을 보존한다. 이는 [보완 기록](../quality-repair-v1/README.md)의
정책·테스트 결과이지 디자인 품질 향상이 실증됐다는 주장이 아니다. 로컬 CLI에는
인증된 호스트 receipt 연동이 없어 최종 APPROVED를 발행하지 못한다.

향후 확장 판단은 새 기능의 수가 아니라, 기존판이 놓친 실제 결함을 동일한
입력·자산·뷰포트·작업 조건에서 개선안만 해소하고 전체 화면 마감을 악화시키지
않는지에 근거해야 한다. 이번 결정에는 추가 시험이나 설치 변경이 포함되지 않는다.
