# JOEDESIGN Harness 결함 발견 비교 시험

**결론: 이 한 사례에서 개선 Harness의 추가 효과는 관찰되지 않았다.** 기존 A와 개선 B가 사전 지정 5개 결함을 모두 발견하고 제안한 코드를 실제 브라우저에서 모두 수정했다. 이는 두 버전이 이 작은 결함 과제에 성공했다는 뜻이다. 미적 완성도나 일반적인 설계 능력의 동등성·우월성은 판정할 수 없다.

| 평가 | 기존 A | 개선 B |
|---|---:|---:|
| 사전 지정 결함 발견 | 5/5 | 5/5 |
| 실제 화면/동작 수정 | 5/5 | 5/5 |
| 추가로 발견한 실제 겹침 | 1 | 1 |
| 관찰된 잘못된 수정 | 0 | 0 |
| 의도된 왼쪽 P 돌출 보존 | 예 | 예 |

## 실행 방법
- 새 PIVOT 오디오 제품 한 페이지. MORO를 사용하지 않았다.
- 같은 JOEDESIGN core, 같은 제품 명세/원본 HTML/다섯 장의 실제 Chromium 캡처. Harness 버전만 다르다.
- 모델 gpt-6-astra, reasoning high, 각 조건 독립 실행 1회. 응답 이벤트에 도구 호출은 없었다.
- 양쪽에서 구체적인 발견 설명과 완성 HTML을 받았고 각각 별도 파일로 저장했다. 이후 Chrome에서 1280×800 및 390×844를 확인했다.
- 정답표와 입력 해시는 모델 실행 전에 고정했다. 모델에게 정답표는 전달하지 않았다.

## 브라우저에서 확인한 수정
1. 제품과 조작 버튼의 중심 차이: A/B 모두 데스크톱과 모바일에서 0px.
2. 다이얼/받침 지름 비: A/B 모두 데스크톱 0.6103, 모바일 0.612. 명세의 44/72≈0.6111와의 차이는 0.001 미만.
3. 로더: 양쪽 모두 중심 (120,120)의 동심원 외측 r90, 내측 r55, 채움 중심 r72.5·선폭35로 경계가 일치했다. 모바일에서 규격 문구와 겹치던 도면은 아래로 이동했다.
4. 푸터 PIVOT: 실제 글자 범위가 양쪽 뷰포트의 컨테이너 안에 들어왔다. A의 우측 경계는 데스크톱 1114.78<1201, 모바일 326.20<351px. B는 1146.63<1201, 335.36<351px.
5. 모바일에서 같은 제스처로 두 안 모두 다이얼이 101° 회전했다. 받침 중심은 187.5px로 고정, 받침 transform 없음. RESET→0°, ArrowRight→10°, 색상 선택 전환 확인.

카피, 네비게이션, 섹션 순서, 배경색과 의도적인 왼쪽 P 돌출은 유지됐다. 첫 화면을 두 안 모두 실제 캡처로 열어 확인했다.

## 실행 차단과 우회하지 않은 대안
기본 CLI 0.146.0은 Astra 모델 버전 조건으로 시작 전에 거절됐다. 최신 설치 CLI 0.158.0-alpha.2.1의 직접 파일 접근 실행도 두 조건 모두 스킬 파일 읽기 명령이 `blocked by policy`로 거절됐다. 이 시도는 점수에 넣지 않았다. 정책을 약화하거나 권한을 높이지 않고, 부모 작업에서 읽을 수 있는 동일 파일 내용을 프롬프트에 포함하고 이미 수집한 이미지를 첨부했다. 모델 실행은 read-only 및 무도구였고, 최종 HTML은 별도 검증자가 저장해 브라우저에서 확인했다.

## 한계
이 결과는 단일 새 페이지, 1회씩의 근접 전이 결함 수리에만 적용된다. 모든 고장 모드에서 두 Harness가 같은 수준이라는 근거가 아니다. 미적 품질, 긴 디자인 제작 과정, 반복 실패 처리, 사용자 만족은 측정하지 않았다. 자동 실행 정책이 계속 파일 읽기를 차단하므로 실제 에이전트가 스킬을 파일에서 읽고 도구를 사용해 작업하는 전체 흐름은 이번 시험에서 확인되지 않았다.

관련 자료: controller/truth.json(사전 기준), controller/frozen-inputs.json(입력 해시), controller/*selfcontained-prompt.txt(전달 입력), controller/*selfcontained-events.jsonl(실행 기록), arm-a·arm-b/FINDINGS.md 및 proposed.html(결과), controller/*verified.png(수정 후 화면), controller/results.json(기계 판독 결과). 이전 실행 차단 기록도 controller에 보존했다.
