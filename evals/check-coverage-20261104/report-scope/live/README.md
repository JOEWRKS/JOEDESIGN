# 직접 실측 — 브라우저 시험 8건 (2026-11-05)

각 시험의 최종 작업 폴더를 `npx vite build --outDir live/<시험>-dist`로 고정 빌드하고 `python -m http.server`(포트 5611~5618)로 띄운 뒤, 내장 브라우저에서 `m.js`를 넣어 쟀다.

- 재는 양: `.hud`·`.cta-area` 안에서 위아래로 이웃한 블록의 **보이는 간격** = 위 블록(또는 그 안 요소)의 가장 아래 그려진 가장자리(상자 아래 + 아래쪽 box-shadow) → 다음 블록 상자 윗변. 시험의 검사 스크립트와 따로 만든 방법이다.
- 크기: 1440×900, 390×844.
- 상태: (1) 시작 화면 실제 상태, (2) 합성 상태 — 엔진 파일이 없어 대국을 시작할 수 없으므로 `data-phase=human`으로 바꾸고 숨은 블록(내 수 카드·간이 분석·후보 알약·금수/엔진 안내·되돌리기 안내)을 모두 띄웠다. 실제 대국에서 동시에 나오지 않는 조합이라 넘침·영역 사이 간격은 판단하지 않고, 이웃 블록 사이 간격만 본다.
- 한계: 두 크기, 합성 상태 하나. 카드 안쪽 여백·가로 간격·넘침은 재지 않았다.
