메인 화면(시작 화면과 대국 화면) 간격 규칙을 정해 코드에 맞췄고, 검사 스크립트를 추가했습니다. 1440×900과 390×844에서는 규칙 위반 0건입니다. 다만 작은 휴대폰(375×667, 360×640)의 복기 화면에서 말풍선 아래가 잘리는 문제가 남았습니다. 이 문제는 이번 수정 전부터 있었습니다. 커밋은 하지 않았습니다.

- **작업**
  - 간격 규칙을 4px 단위 값 몇 개로 정해 `src/style.css`에 반영했습니다: 카드·줄 사이, 카드 안 줄 사이, 카드 안쪽 여백, 같은 줄 버튼 사이, 버튼 높이.
  - 버튼과 카드 밑의 입체 그림자 두께가 3~10px로 제각각이어서, 상자끼리 간격이 같아도 눈에는 달라 보였습니다. 그래서 간격을 그림자 끝부터 재도록 바꿨습니다. 예를 들어 큰 버튼 바로 아래 안내 줄은 눈으로 1~2px만 떨어져 있었는데, 이제 16px(휴대폰 12px)입니다.
  - 내용이 없는 아래 안내 줄(시작·종료·복기 화면)은 자리를 차지하지 않게 했습니다.
  - 검사 스크립트 `work/design/spacing-check.mjs`를 추가했습니다.
    - 엔진 파일이 없어도 돌도록 엔진 응답을 합성값으로 바꿉니다.
    - 두 지정 크기에서 9개 상태(시작, 첫 안내, 후보, 착수 예정, 착수 뒤, 종료, 복기, 안내 줄 3종)의 실제 화면을 잽니다. 안내 줄 3종은 숨김을 풀어 띄운 합성 상태입니다.
    - 다른 5개 크기는 화면 넘침만 확인합니다.
    - 종료 코드: 0 통과, 1 규칙 위반, 2 참고 크기에서만 넘침.
  - 실행: `npx vite build` 후 미리보기 서버를 띄우고 `GOMOKU_DEV_PORT=5601 node work/design/spacing-check.mjs`.
- **업데이트 파일**
  - `src/style.css`
  - `work/design/spacing-check.mjs` (신규)
  - `DESIGN.md`: 간격 규칙 절, 값 표, 무엇을 어디서 검사하는지 표
  - `TASK.md`
  - `ROADMAP.md`: 현재 줄, CO2
  - `ISSUES.md`: LAYOUT-05
  - 캡처 `work/design/shots/spacing-*.png`
- **이슈**
  - 수정 전에는 규칙 위반이 179건이었습니다. 말풍선 안쪽 여백이 10~22px로 섞여 있었고, 후보 버튼 사이 6/10px, 보조 버튼 높이 36~46px 등이 제각각이었습니다.
  - 작은 휴대폰 복기 화면 잘림(LAYOUT-05)은 수정 전 빌드에서도 같은 두 크기에서 측정됐습니다.
- **해결**
  - 1440×900·390×844 두 크기에서 규칙 위반 0건, 미확인 0건입니다.
  - 일부러 간격을 틀어 본 빌드에서는 스크립트가 위반을 잡아 실패했습니다(종료 코드 1). 확인 뒤 원래 CSS로 되돌렸습니다.
  - 작업 중 768×1024 복기 화면이 잘렸지만, 빈 안내 줄 숨김으로 해소했습니다.
  - `npx tsc --noEmit` 통과, `npx vitest run` 87개 통과(1개 건너뜀). 캡처는 직접 확인했습니다.
- **남은 문제**
  - LAYOUT-05가 열려 있어 현재 스크립트는 종료 코드 2로 끝납니다.
  - 간격 값은 제가 정한 제안이라 사용자 확인 전입니다.
  - Playwright E2E는 엔진 파일이 없어 돌리지 않았습니다.
  - JOEDESIGN이 요구하는 전문 검토(Impeccable, UI UX Pro Max, web-design-guidelines)와 규칙 정리의 독립 검토는 하지 않았습니다. 이 폴더에서 쓸 수 없었습니다.
  - 측정은 합성 엔진 응답 기준이라 실제 문구 길이는 반영되지 않았습니다.
  - 데스크톱에서 오른쪽 첫 카드와 판 윗변이 약 6px 어긋납니다. 이번 규칙 범위 밖입니다.
- **다음 작업**

  - LAYOUT-05는 무엇을 접을지 정해야 합니다. 기준 수 문장은 DESIGN상 필수라서 숨기려면 사용자 확인이 필요합니다.
