간격 규칙을 정해서 DESIGN.md에 적고 `src/style.css`에 맞췄고, 검사 스크립트 `work/design/spacing-check.mjs`도 추가했습니다. 이 세션에서는 브라우저를 쓸 수 없어서 실제 화면에서 간격이 고르게 보이는지는 아직 확인하지 못했습니다. 규칙 값도 제가 정한 제안이라 승인이 필요합니다.

**원인:** 블록 사이 간격 값 자체는 일정했습니다. 그런데 카드와 버튼 아래의 입체 그림자가 그 간격을 블록마다 다르게 덮었습니다. 코드로 계산하면 실제로 보이는 간격은 이랬습니다.
- 말풍선 아래 4px, 키 작은 데스크톱 화면에서는 0px
- 평가 카드 아래 7px
- 주 버튼 줄 아래 1px, 휴대폰에서는 2px
- 금수·엔진 안내 아래 16px
- 나란한 버튼 사이도 6·8·10·12px이 섞여 있었습니다.

- **작업**
  - DESIGN.md에 규칙 세 가지를 적었습니다(상태: 제안).
    - S1: 카드·버튼 줄·안내 줄 사이의 보이는 세로 간격은 12px, 휴대폰 10px, 키 작은 화면 8px.
    - S2: 그림자가 있는 블록은 그림자 높이만큼 아래 여백을 확보합니다. 그래서 보이는 간격이 항상 S1 값이 됩니다.
    - S3: 나란한 버튼 사이 가로 간격은 10px, 휴대폰 8px. 공간이 아주 좁을 때만 쓰는 예외 두 개를 함께 적었습니다.
  - 값 표와 "어떤 검사가 어디까지 재는지" 표도 같이 적었습니다. 이 규칙은 시작 화면과 대국 화면에 모두 적용됩니다.
  - `src/style.css`를 이 규칙에 맞게 고쳤습니다. 함께 바뀐 점:
    - 취소 버튼 그림자를 옆 버튼과 같은 깊이로 맞췄습니다(5px → 7px, 휴대폰 6px).
    - 금수·엔진 안내 아래의 여분 여백 8px을 없앴습니다.
    - 버튼 영역이 그림자만큼 커져서 판 크기 계산에 쓰는 값을 늘렸습니다(132→144px, 휴대폰 112→120px). **화면 높이가 판 크기를 정하는 경우에는 판이 최대 12px(휴대폰 8px) 작아집니다.**
  - 검사 스크립트는 CSS 코드를 읽어 규칙 위반을 줄 번호와 함께 알려 줍니다.
- **업데이트 파일:** `src/style.css`, `DESIGN.md`, `TASK.md`(2026-11-05 항목), `ROADMAP.md`(현재·다음 줄, CO2 근거), `work/design/spacing-check.mjs`(새 파일). 커밋하지 않았습니다.
- **이슈:** `npx tsc --noEmit`을 실행하지 못했습니다. 이 폴더의 `node_modules`가 바깥의 다른 폴더를 가리키는 링크이고 실행 파일 폴더(`.bin`)가 없습니다. 그래서 npx가 이름만 같은 엉뚱한 `tsc` 패키지를 npm 캐시에 받아 실행했고 실패했습니다. 프로젝트 파일은 바뀌지 않았고, 이번 변경은 CSS와 스크립트뿐이라 TypeScript 소스는 손대지 않았습니다.
- **해결:** 없음. 실제 화면에서 확인하지 못했으므로 해결로 보지 않습니다.
- **남은 문제**
  - 검사 결과 `spacing-check` 위반 0건입니다. 단, `src/style.css` 코드만 읽고 화면 조건 4가지(기본, 폭 700 이하, 높이 700 이하, 둘 다)를 계산한 것입니다. 실제 화면은 재지 않았고, 화면에서 잰 값과 한 번도 맞춰 보지 않았습니다.
  - 스크립트가 위반을 잡는지는 확인했습니다. 수정 전 CSS에 돌리면 위반이 여러 건 나오고, 간격 두 곳을 일부러 바꾼 사본에서는 그 두 건만 정확히 잡습니다.
  - 단위 테스트(`npx vitest run`)는 87개 통과, 1개 건너뜀입니다. CSS는 검사하지 않는 테스트입니다.
  - E2E 테스트, 12개 크기 넘침 검사, 실제 화면 확인은 하지 않았습니다.
  - 말풍선이 공간에 맞춰 내용을 접는 기준이 몇 px 움직였을 수 있습니다.
  - 판과 말풍선 사이, 말풍선 영역과 버튼 영역 사이 간격은 남는 높이가 들어가는 구간이라 이번 규칙에 넣지 않았습니다. 카드 안쪽의 글줄 간격도 범위 밖입니다.
  - 규칙 값(12/10/8, 10/8)은 제가 고른 것이라 확인이 필요합니다.
- **다음 작업:** 브라우저를 쓸 수 있는 세션에서 실제 화면의 간격을 재어 스크립트 결과와 맞춰 봅니다. 대상은 1440×900, 390×844, 360×640 크기에서 말풍선→후보 줄, 주 버튼 줄→하단 안내 줄입니다. 이어서 E2E와 넘침 검사를 다시 돌리고, 사용자에게 간격 값 승인을 받습니다.
