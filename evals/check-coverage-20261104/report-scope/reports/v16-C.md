간격 규칙을 정해 DESIGN.md에 적고, src에 맞추고, 검사 스크립트를 추가했습니다. 검사는 CSS 코드를 읽어서만 확인했고, 화면 렌더는 이 세션에서 띄울 수 없어 보지 못했습니다. 그래서 실제 화면에서 간격이 고르게 보이는지는 아직 확인되지 않았습니다.

- **작업**
  - 원인(코드에서 찾음): 카드와 버튼 아래의 입체 그림자(3~8px)가 블록 사이 간격을 잡아먹고 있었습니다. 그래서 눈에 보이는 틈이 같은 종류인데도 데스크톱 1~16px, 휴대폰 2~16px로 달랐습니다.
    - 말풍선 아래 4px
    - 큰 버튼 줄과 그 아래 고지문 줄 사이 1px
    - 금수·엔진 안내와 버튼 사이 16px
  - 정한 규칙(DESIGN.md "간격 규칙", 제안 상태):
    - S1 블록 사이: 도움말 칸과 버튼 칸에서 위아래 블록 사이에 보이는 간격은 10px로 맞춥니다. 폭이나 높이가 700px 이하인 화면은 8px입니다. 보이는 간격은 위 블록 그림자 끝부터 다음 블록 테두리까지입니다.
    - S2 버튼 사이: 옆으로 놓인 버튼 사이는 10px, 휴대폰은 8px입니다. 좁은 칸에서 접히는 두 줄만 6px입니다.
    - S3 그림자 자리: 그림자가 있는 블록은 그림자 높이만큼 아래 여백을 둡니다. 그러면 칸에 정한 간격이 그대로 보이는 틈이 됩니다.
    - S4 판 크기 계산: 판 크기를 정할 때 빼 두는 버튼 칸 높이도 같은 값으로 계산합니다.
  - `src/style.css`의 바뀐 점:
    - 간격·그림자 값을 맨 위(`:root`) 한 곳에서 정하고 모든 곳이 그 값을 씁니다.
    - 숫자를 직접 적은 간격(6·8·10·12px 섞임)을 모두 없앴습니다.
    - 취소 버튼 그림자를 두기 버튼과 같게, 첫 안내 그림자를 말풍선과 같게 맞췄습니다.
  - 새 검사 스크립트 `node work/design/spacing-check.mjs`: 어긋나면 위치와 이유를 보여 주고 실패로 끝납니다.
  - 검사 결과(모두 코드 기준, 화면 렌더 아님):
    - 고치기 전 106건 → 고친 뒤 0건. 범위는 S1~S4, 도움말 칸 6개·버튼 칸 5개 블록입니다. 간격 값은 1440×900, 1280×680, 768×1024, 800×650, 390×844, 360×640 여섯 크기에서 계산했습니다.
    - 일부러 어긋나게 만든 CSS 6개를 넣었더니 스크립트가 6개 모두 잡았습니다.
    - 타입 검사(`tsc --noEmit`) 통과, 단위 검사 88개 중 87개 통과·1개 건너뜀입니다. 건너뛴 1개는 엔진 대조 검사로, 필요한 엔진 사본 파일이 이 폴더에 없어서 실행되지 않았습니다.

- **이슈**
  - 간격이 고르게 맞는 대신 블록 사이 실제 공간이 늘어납니다. 도움말 칸 내용 높이가 데스크톱 약 5px, 휴대폰 약 2px 길어지고, 높이 700px 이하 화면에서는 약 14~17px 길어집니다. 이 칸은 넘치면 잘리고 높이에 따라 덜 중요한 것부터 접히므로, 키 작은 화면에서 후보 줄이 잘리거나 접히는 시점이 바뀔 수 있습니다.
  - 판 크기 계산에 빼 두는 버튼 칸 높이가 132→140px(휴대폰 112→115px)로 바뀌었습니다. 높이 때문에 판 크기가 정해지는 화면에서는 판이 최대 8px 작아질 수 있습니다.
  - `npx tsc`가 이 폴더에 있는 TypeScript를 찾지 못해, 관련 없는 `tsc@2.0.4` 패키지를 npm 캐시에 받았습니다. 실행은 안내문 출력뿐이었고 프로젝트 파일은 바뀌지 않았습니다. 타입 검사는 `node_modules/.bin/tsc`로 다시 돌려 통과했습니다.

- **해결**: 코드 수준에서 간격 규칙 어긋남 0건. 화면에서 고르게 보이는지는 아직 검증 전이라, 아래 남은 문제가 해결되기 전에는 완료로 보지 않습니다.

- **남은 문제**
  - 화면 렌더 확인: 넘침·잘림·접힘을 보지 못했고, 검사 결과를 실제 화면 한 곳을 직접 재서 대조하는 확인(spot-check)도 하지 않았습니다. 그래서 DESIGN.md 표의 모든 검사 행이 "not spot-checked"입니다.
  - 간격 값(10/8px)과 바뀐 그림자(취소 버튼, 첫 안내, 휴대폰 복기 칸)에 대한 사용자 시각 확인.
  - 그 밖에 전부터 열려 있던 CO2 항목(문구·화면 수락, 휴대폰 실기기 측정 등)은 그대로입니다.
  - 아무것도 커밋하지 않았습니다.
