간격 규칙을 DESIGN.md에 적고 `src/style.css`를 거기에 맞췄으며, 다시 어긋나지 않게 잡는 검사 스크립트를 `work/design`에 추가했습니다. 검사는 통과했지만 브라우저를 못 써서 실제 화면에서 간격이 맞는지는 아직 확인하지 못했습니다.

**간격이 제각각이던 이유:** 블록 사이 gap 값 자체는 대부분 같았습니다. 그런데 버튼과 카드 아래로 떨어지는 입체 그림자(3~10px)가 그 간격을 먹어서, 눈에 보이는 간격이 1~22px로 달랐습니다. 아래 수치는 화면에서 잰 값이 아니라 CSS 값으로 계산한 값입니다.
- 주 버튼과 아래 고지문 줄 사이가 1px
- 말풍선과 후보 줄 사이가 4px
- 금수 안내와 버튼 사이가 16px (여백이 이중으로 들어감)
- 휴대폰 주 버튼은 그림자가 6px인데 누르면 7px 내려갔습니다.

**정한 규칙:** "보이는 간격"을 위 요소의 그림자 끝에서 다음 요소 테두리까지로 정했습니다. 그림자 깊이는 요소마다 값 하나로 그리고, 같은 값만큼 아래 여백을 확보합니다. 그래서 간격 값이 곧 눈에 보이는 간격이 됩니다.
- **블록 사이 세로 간격:** 12 / 10 / 8px (기본 / 폭 700 이하 / 높이 720 이하)
- **한 줄 안 버튼 사이:** 10 / 8px
- **판(또는 시작 제목) → 말풍선 영역 → 버튼 영역:** 16 / 12 / 10px
- **예외 두 곳:** 공간이 아주 좁을 때 버튼을 한 줄에 넣으려고 버튼 사이 간격만 6px·8px로 줄입니다.
- 규칙 5개, 값 표, 각 규칙을 무엇으로 검사하고 무엇을 아직 재지 않았는지가 DESIGN.md에 함께 있습니다.

- **이슈:**
  - Git Bash에서 `npx tsc`·`npx vitest`가 프로젝트에 깔린 도구를 찾지 못했습니다. 그 결과 npm에서 이름만 같은 무관한 패키지 `tsc@2.0.4`가 프로젝트 밖 npm 캐시에 받아졌습니다. 이 패키지는 안내 문구만 출력하고 프로젝트 파일은 바꾸지 않았습니다. 이후에는 프로젝트의 도구를 `node`로 직접 실행했습니다.
  - 검사 스크립트를 처음 돌렸을 때, 일부러 규칙을 어긴 CSS 9가지 중 2가지를 놓쳤습니다(같은 셀렉터 규칙을 중복으로 걸러낸 버그). 고친 뒤 9가지 모두 잡습니다.
