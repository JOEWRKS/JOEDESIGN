메인 화면에 간격 규칙을 정하고 CSS를 맞췄으며, 검사 스크립트도 추가했습니다. 다만 작은 휴대폰의 복기 화면은 아직 말풍선 칸이 잘려 검사가 실패합니다. 변경 전에도 잘렸는데 간격을 넓히면서 더 많이 잘리게 됐습니다. 정한 값은 제가 제안한 것이라 확인이 필요합니다.

- **작업:**
  - 고치기 전에 쟀더니 카드·버튼·안내 줄 사이 간격이 1~16px로 제각각이었습니다(버튼과 안내 줄 사이 1~3px, 말풍선과 후보 알약 사이 4px, 금수 안내와 버튼 사이 16px). 버튼끼리 간격은 6~12px, 카드 안쪽 여백은 8~16px였습니다. 주원인은 버튼·카드 아래 그림자 두께(3~8px)를 간격 계산에서 빼지 않은 것이고, 크기별로 흩어진 값도 섞여 있었습니다.
  - 규칙은 "보이는 가장자리(그림자 포함) 기준"으로 정했습니다:

    | 대상 | 넓은 화면 | 휴대폰(폭 700 이하) |
    | --- | --- | --- |
    | 블록 사이·버튼 줄 간격 | 12px | 8px |
    | 시작 화면 구역 간격 | 24px | 16px |
    | 말풍선 안쪽 여백(위아래/좌우) | 16/20px | 12/16px |
    | 작은 카드 안쪽 여백 | 12/16px | 8/12px |
    | 안내 줄 안쪽 여백 | 8/12px | 4/12px |

  - CSS에 이 값들을 공통 변수로 넣었습니다. 그림자가 있는 블록은 그 깊이만큼 아래 여백을 더해, 지정한 간격이 화면에 보이는 간격과 같아지게 했습니다. 크기별로 흩어진 덮어쓰기 값은 지웠습니다.
  - 간격이 넓어진 만큼 판 크기 계산을 보정했습니다. 말풍선 칸이 아주 짧을 때 접는 규칙 2개도 새로 넣었습니다: 160px 이하에서 후보 알약, 120px 이하에서 말풍선 라벨을 숨깁니다(판 위 숫자·좌표·%는 남음).
  - 엔진 파일이 이 폴더에 없어서, 화면 상태는 가짜 엔진 응답으로 만들었습니다. 승률·후보 값은 실제 값이 아닙니다.
