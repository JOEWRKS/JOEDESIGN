간격 규칙을 정해 DESIGN.md에 적고, src를 거기에 맞추고, 검사 스크립트를 work/design에 추가했습니다. 검사는 위반 0건입니다. 다만 브라우저를 못 써서 실제 화면은 보지 못했고, 바뀐 간격이 한 화면에 그대로 들어가는지도 아직 모릅니다.

**원인 (코드에서 확인):** 카드와 버튼에는 아래로 3~8px 튀어나오는 입체 그림자가 있습니다. 그런데 간격은 테두리 기준으로 잡혀 있어서, 그림자 깊이만큼 실제로 보이는 간격이 줄어들었습니다. 그래서 보이는 간격이 1~16px로 제각각이었습니다.
- 데스크톱: 주 버튼과 그 아래 줄 사이 1px, 말풍선과 후보 줄 사이 4px, 금수 안내와 버튼 사이 16px.
- 휴대폰: 말풍선과 후보 줄 사이 4px, 버튼과 아래 줄 사이 2px.
- 카드 안 글 줄 간격과 한 줄 안 버튼 간격에도 6·8·10·12·14px가 섞여 있었습니다.

**정한 규칙 (값은 데스크톱 / 휴대폰):**
- **S1 블록 사이:** 위 블록의 그림자 끝에서 다음 블록까지 12 / 8px. 각 블록이 자기 그림자 깊이만큼 아래로 비켜 서게 해서 보정했습니다.
- **S2 한 줄 안 버튼·글 사이:** 12 / 8px.
- **S3 카드 안쪽 여백:** 큰 카드 16·20 / 12·16, 작은 카드 12·16 / 8·12, 안내 줄 4·12.
- **S4 카드 안 글 줄 사이:** 8 / 4px. 카드 안 버튼 묶음 앞은 S1 값.
- **S5 말풍선 영역과 버튼 영역 사이:** 16px.
- 모든 간격은 4px 단위(4·8·12·16·20)에서만 고릅니다.

**알아두실 변경:**
- 취소 버튼 그림자를 5px에서 7px로 올려 같은 줄 버튼과 맞췄습니다.
- 첫 안내 그림자를 7px에서 8px로 올려 말풍선과 맞췄습니다.
- src에서 켜는 코드가 없는 "자세히 보기" CSS 규칙을 지웠습니다.

**바뀐 파일:**
- `src/style.css`: 간격 토큰을 추가하고 숫자로 적힌 간격을 토큰으로 바꿨습니다.
- `DESIGN.md`: "간격 규칙 — 제안 v1" 섹션(규칙, 토큰 표, 무엇을 검사하고 무엇을 못 재는지 적은 범위표). 상태는 사용자 승인 전 초안입니다.
- `work/design/spacing-check.mjs`: 새 검사 스크립트. `npm run check:spacing`으로 돌립니다.
- `package.json`: 위 실행 명령 추가.
- `TASK.md`, `ROADMAP.md`: 이번 작업 기록과 남은 확인 항목.

**확인한 것:**
- `npm run check:spacing`: 위반 0건.
- 같은 스크립트를 수정 전 CSS에 돌리면 위반 170건이 나옵니다.
- 일부러 넣은 위반 6건(숫자 간격, 블록 자체 여백, 숫자 그림자, 역할 없는 새 블록)을 모두 잡았습니다.
- `npx tsc --noEmit` 통과, `npx vitest run` 87개 통과(1개 건너뜀).
- 커밋은 하지 않았습니다.

**남은 문제:**
- 이 검사는 CSS와 마크업만 읽습니다. 화면에 보이는 실제 간격(px), 한 화면에 다 들어가는지, 12가지 크기에서 넘침이 없는지는 재지 않았습니다.
- 휴대폰에서 버튼 영역이 약 6px 커졌습니다. 390×844 같은 작은 화면에서 말풍선 내용이 접히거나 잘리는지 실제 화면으로 봐야 합니다.
- CSS가 바뀌었으므로 이전 E2E와 넘침 검사 결과는 지금 코드에 대한 근거가 아닙니다.
- 판과 말풍선 영역 사이 간격은 판 크기 계산과 묶여 있어 이번에 바꾸지 않았습니다.
