간격 규칙을 정해 DESIGN.md에 적고 `src/style.css`를 거기에 맞췄습니다. 다시 어긋나지 않게 잡는 검사 스크립트도 `work/design/spacing-check.mjs`로 추가했습니다. 다만 모두 코드로만 확인했고, 브라우저로 실제 화면을 보지 않아서 보이는 간격이 고르게 맞는지는 아직 확인되지 않았습니다.

**제각각으로 보인 이유:** 카드와 버튼 사이 간격 값 자체는 정해져 있었지만, 카드·버튼 아래로 떨어지는 그림자(3~10px)가 그 간격을 덮었습니다. 그래서 실제 보이는 간격이 쌍마다 1~16px로 달랐습니다. CSS 값으로 계산한 예시입니다.
- 넓은 화면: 큰 버튼→아래 줄 1px, 말풍선→후보 알약 4px, 금수 안내→버튼 16px
- 휴대폰: 판→말풍선 5px

- **작업:**
  - 간격 규칙 S1~S5를 정했습니다.
    - S1: 위아래로 쌓이는 카드·버튼 줄·안내 줄 사이 보이는 간격은 넓은 화면 12px, 휴대폰 10px, 키 작은 화면 8px입니다. 시작 화면은 기존 18px(키 작은 화면 10px)를 그대로 씁니다.
    - S2: 그림자 깊이만큼 아래 여백을 더해서 그림자가 간격을 먹지 않게 했습니다.
    - S3: 한 줄에 있는 버튼은 같은 그림자 깊이를 씁니다.
    - S4: 한 줄 안 가로 간격은 10px(휴대폰 8px)입니다. 공간이 좁을 때만 8px입니다.
    - S5: 버튼 아래 줄이 비면 자리를 차지하지 않습니다.
  - 이 규칙을 CSS에 적용하고 검사 스크립트를 만들었습니다.
- **업데이트 파일:** `src/style.css`, `DESIGN.md`("간격 규칙" 절, 토큰 표·규칙별 검사 범위 표), `work/design/spacing-check.mjs`(새 파일), `package.json`(`npm run check:spacing`), `TASK.md`(2026-11-05 항목), `ROADMAP.md`(현재·다음 작업 줄).
- **이슈:**
  - `npx tsc --noEmit`은 돌리지 못했습니다. 프로젝트에 TypeScript가 설치돼 있지 않아서, npx가 이름만 같은 다른 패키지(`tsc@2.0.4`)를 받아 안내문만 출력했습니다. 이번 변경은 TS 파일을 건드리지 않았습니다.
  - `node_modules`가 작업 폴더 바깥 폴더를 가리키는 링크라서 설치는 하지 않았습니다. 그래서 단위 테스트는 npx가 받아 온 vitest 5.1.0으로 돌았습니다(package.json은 5.0.5).
  - 사용자가 직접 요청하지 않은 화면 변화가 세 가지 있습니다.
    - 시작 화면과 복기 화면에서 빈 아래 줄(44px)이 사라집니다.
    - 세로 배치이면서 화면 높이가 판 크기를 정하는 경우, 판이 최대 약 17px 작아집니다. 390×844는 계산상 변화가 없습니다.
    - 취소 버튼 그림자가 5px에서 7px로 바뀌었고, 좁을 때 후보 알약 사이 간격이 6px에서 8px로 바뀌었습니다.
- **해결:**
  - 간격 검사 스크립트는 규칙 5개 모두 위반 0입니다. 이 결과는 CSS 규칙 416개(모든 미디어·컨테이너 조건 포함)와 `src/main.ts` 화면 구조를 읽은 코드 검사이고, 화면 크기·상태와 무관하게 선언만 본 것입니다. 실제 화면 측정은 아닙니다.
  - 고치기 전 CSS에 같은 스크립트를 돌리면 위반 61건(S1 12, S2 35, S4 13, S5 1)으로 실패합니다. 어긋남을 실제로 잡아낸다는 뜻입니다.
  - 단위 테스트(`npx vitest run`)는 87개 통과, 1개 건너뜀입니다.
- **남은 문제:**
  - 렌더 확인을 아직 하지 않았습니다. 보이는 간격이 실제로 고른지, 12개 화면 크기에서 넘침이 0인지, E2E 테스트와 tsc가 통과하는지 모릅니다. JOEDESIGN 절차에서 요구하는 "스크립트 판정과 실제 보이는 가장자리 대조"도 하지 않아서, DESIGN.md 표에 "not spot-checked"로 적었습니다.
  - 간격 값(12/10/8px)은 제안이고 사용자 승인은 아직 없습니다.
  - 카드 안 글줄 간격, 화면 바깥 여백, 상단 대결줄, 도움말·새 게임 확인 창은 규칙 범위 밖입니다.
