설명 카드 안 보조 글자(`.caption`)를 12px에서 13px로 올렸습니다. 두 화면 크기에서 실제로 13px로 나오는 것을 확인했고, 디자인 검사도 이전과 같은 결과입니다. 다만 이번 검사는 원래 글꼴이 아닌 대체 글꼴로 했습니다.

- **작업:** `src/style.css` 155행의 `.caption` 글자 크기를 바꿨습니다. 이 규칙을 쓰는 설명 카드 안 글자는 엔진 준비 문구, 복기 결과·맥락 문구, "짧은 탐색으로 고른 한 가지 예상이에요…" 안내입니다. 복기 카드의 `#review-context`는 따로 11px로 정해져 있어 그대로입니다.
- **업데이트 파일:**
  - `src/style.css`
  - `DESIGN.md`: 작은 글자 행에 "캡션 13px, 2026-11-09 사용자 지시"를 적었습니다.
  - `TASK.md`: 새 기록 "2026-11-09 — 설명 카드 캡션 12px → 13px"(`#caption-13`)을 추가했습니다.
  - ROADMAP은 상태가 바뀐 항목이 없어 그대로 두었습니다.
  - 커밋은 하지 않았습니다.
- **이슈:**
  - 390×844에서 엔진 실패 문구 "엔진을 불러오지 못해 시작할 수 없어요. 새로 고침해 주세요."가 한 줄(18px)에서 두 줄(39px)로 늘어납니다.
  - 이번 dev 서버에서는 글꼴 파일이 403으로 막혔습니다. `node_modules`가 작업 루트 밖 폴더를 가리켜 Vite가 열어 주지 않아서입니다. 그래서 Jua·Pretendard 대신 대체 글꼴로 쟀습니다. 설정은 고치지 않았습니다.
- **해결:** 1440×900과 390×844에서 캡션 네 요소가 모두 13px로 계산되는 것을 확인했습니다. `system-audit.mjs --stub` 14장면 결과는 다음과 같습니다.
  - 색, 글자 최소 크기, 누르는 크기 모두 통과
  - 대비는 228/240으로, 기존에 있던 미달 3건만 그대로입니다(새로 생긴 미달 없음)
  - 화면 넘침 0, 말풍선 사이 간격도 변화 없음
- **남은 문제:**
  - "설명 카드 안 보조 글자"는 `.caption`으로 해석했습니다. 휴대폰에서 12px인 다른 글자는 그대로입니다. 설명 카드 안의 `.hero-sub`(좌표 아래 부제)와 복기 카드의 `#review-label`·`#review-text`, 카드 밖의 `.coach-note`·`.branch-note`입니다. 이 중에도 올릴 것이 있는지 알려 주세요.
  - 실패 문구가 두 줄이 되는 것이 괜찮은지 확인이 필요합니다. 실제 글꼴로는 줄바꿈이 달라질 수 있습니다.
  - 엔진 파일이 없어 E2E는 실행하지 못했습니다.
- **다음 작업:** 위 범위를 확인해 주시면 필요한 곳을 더 고치겠습니다. 글꼴이 정상으로 불러와지는 환경에서 휴대폰 화면을 다시 재 볼 수 있습니다.
