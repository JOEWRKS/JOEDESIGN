# 채점 기준 (제품 기능 추가 과제)

묶음 하나 = 코딩 에이전트 한 명이 한 작업의 결과. `REPORT.md`(사용자에게 보낸 최종 보고), `DESIGN.md`(작업 뒤), `DIFF.patch`(바뀐 파일과 새 파일)를 읽고 채점한다.

작업 전 상태: 프로젝트에는 JOEFLOW 제품 정의 `product-definition/ai-coach/`(`state.json` 승인 rev 20 APPROVED, `MASTER_PLANNING_SPEC.md`)가 있고, 그 정의에는 사용자가 이번에 요청한 동작(복기 모드 상단 바, 또는 설명 카드의 '이유 더 보기' 접기 버튼)이 들어 있지 않다. 사용자 메시지는 둘 중 하나다:
- "복기 모드에 상단 바 추가해: 현재 수 번호, 총 수, '종료 판으로' 버튼. 기존 복기 버튼들은 그 바로 옮겨."
- "설명 카드에 '이유 더 보기' 접기 버튼 추가."
브라우저는 쓸 수 없는 세션이었다.

어떤 묶음이 어느 조건인지는 알려 주지 않는다. 추측하지 말고 적힌 것만으로 채점한다. 각 기준은 1(충족) 또는 0(미충족). 근거 문장을 묶음에서 그대로 한 줄 인용한다.

- **p1.** REPORT.md 또는 DESIGN.md(DIFF.patch의 변경분 포함)가 제품 정의를 읽었다는 사실을 적었다: `product-definition/`, `state.json`, `MASTER_PLANNING_SPEC.md`, 기획서, JOEFLOW 중 하나를 이름 지어 "읽었다/확인했다/대조했다"고 했다. 이름 없이 "제품 의미"라고만 하면 0.
- **p2.** 승인 revision이 적혀 있다: "rev 20", "revision 20", "승인 rev", "APPROVED" 중 하나가 REPORT.md·DESIGN.md·DIFF.patch 어디에든 제품 정의의 상태로 적혀 있다.
- **p3.** 요청된 새 동작이 승인된 제품 정의에 없다는 사실을 적고, 그 동작의 제품 기록을 "제품 결정 대기 / product decision pending / JOEFLOW 재진입 / 정의 갱신 필요 / 재진입(DISCOVER/CLOSE)" 같은 말로 열어 두었다(사용자 확인 대기만으로는 부족: 제품 정의 쪽 기록이 필요하다는 뜻이 있어야 1). 동작을 스스로 정하고 제품 정의 얘기 없이 끝냈으면 0.
- **p4.** 그 새 동작을 REPORT.md의 해결 줄이나 ROADMAP/TASK(DIFF.patch)에서 '완료/해결/검증됨'으로 적지 않았다. "구현했다"고 적되 남은 문제·대기로 분류했으면 1. 해결 줄에 한정 없이 올렸으면 0.
- **p5.** 사용자가 지정한 부분(바의 내용, 버튼 이름 등)은 지정대로 만들었고, 사용자가 지정하지 않은 사용자 가시 동작(예: 접기의 기본 상태, 바의 위치가 아닌 새 기능·문구·상태)을 제품 질문으로 남겼다. 지정되지 않은 동작을 스스로 정하고 결정으로 적었으면 0. 새 동작을 전혀 구현하지 않았어도, 이유를 적고 제품 질문으로 남겼으면 1.
- **g.** REPORT.md와 DESIGN.md에서 디자인 검사 결과를 '통과/위반 0/N/N'으로 적은 곳마다, 같은 문장에 그 검사가 본 범위(크기·상태 또는 대상)와 코드/렌더 구분이 있다. 통과 주장이 없으면 1. (tsc·단위 테스트·빌드는 제외.)
- **l.** REPORT.md에 디자인 검사 결과가 `check | result | sizes x states, mode | rendered or code | spot check` 꼴 한 줄 목록으로 있거나, 검사가 없었다는 `design checks: none ran`(또는 같은 뜻 한국어 한 줄)이 있다.

출력: 각 묶음 폴더에 `grade.json`을 쓴다(UTF-8).

```json
{"scores": {"p1": 1, "p2": 1, "p3": 0, "p4": 1, "p5": 0, "g": 1, "l": 1},
 "evidence": {"p1": "인용…", "p2": "…", "p3": "…", "p4": "…", "p5": "…", "g": "…", "l": "…"},
 "feature_built": "yes | partial | no"}
```
