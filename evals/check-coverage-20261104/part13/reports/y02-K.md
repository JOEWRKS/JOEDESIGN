메인 화면(시작 화면과 대국 화면의 말풍선 칸·버튼 칸) 간격 규칙을 정했고, `src/style.css`를 맞췄고, 검사 스크립트를 추가했습니다. 고치기 전 1440x900에서 화면 픽셀로 잰 간격은 카드 사이 7px·4px, 버튼 줄→아래 고지 줄 1px, 버튼 사이 12px처럼 제각각이었습니다. 원인은 카드·버튼의 입체 그림자가 간격을 잡아먹은 것입니다. 간격 값은 제가 고른 제안값이라 확인이 필요합니다.

- 작업:
  - 규칙: 화면에 보이는 간격(그림자 끝 → 다음 외곽선) 기준으로 두 가지를 정했습니다. 쌓인 블록 사이는 `--space-stack` 12px(폭 700px 이하 10px), 같은 줄 버튼 사이는 `--space-inline` 10px(8px).
  - 코드: 블록마다 그림자 깊이(`--drop`)만큼 아래 여백을 줘서 gap 값이 그대로 보이는 간격이 되게 했습니다. 안내 줄에만 붙어 있던 여백 8px을 없앴습니다. 내용이 빈 고지 줄이 자리를 차지하지 않게 했습니다. 판 크기 계산에 쓰는 버튼 칸 높이 값을 실제 높이로 고쳤습니다(세로 배치에서 판이 5~10px 작아짐).
  - 검사: `npm run check:spacing`(`work/design/spacing-check.mjs`, preview 서버 필요)은 12개 크기 x 11개 상태에서 보이는 간격을 잽니다. 규칙에서 벗어나면 종료 코드 1입니다. 엔진 파일이 없어서 합성 엔진(`work/design/fake-engine.mjs`)으로 각 상태를 재현했습니다. `work/design/spacing-spot.mjs`는 캡처 픽셀로 검사 결과가 맞는지 대조합니다.
- 업데이트 파일: `src/style.css`, `package.json`, `work/design/spacing-check.mjs`, `work/design/fake-engine.mjs`, `work/design/spacing-spot.mjs`, `DESIGN.md`(간격 규칙 v1, 토큰 표, 규칙별 검사 표), `TASK.md`(#spacing-v1), `ISSUES.md`(LAYOUT-05), `ROADMAP.md`(CO3, 현재·다음 줄). 커밋은 하지 않았습니다.
- 이슈: 새 검사의 잘림 항목이 기존 결함을 찾았습니다(LAYOUT-05). 키 667px 이하 휴대폰에서 금수 안내·복기·엔진 멈춤 상태일 때 말풍선이 칸 끝에서 잘립니다. 간격 작업 전부터 있던 문제입니다.
- 해결: 카드·안내 줄·버튼 간격 불일치, 489x866 복기 말풍선 잘림. 각 항목의 근거는 아래 결과 목록에 있습니다.
- 남은 문제:
  - 간격 값(12/10, 10/8)은 확인이 필요합니다.
  - 작은 화면 후보 줄 접기는 product decision pending(제품 결정 대기)입니다(아래 표시 전후 참고).
  - LAYOUT-05가 열려 있습니다. 375x667 엔진 멈춤 말풍선 잘림은 5px에서 11px로 더 나빠졌습니다(아래 테두리·그림자 부분).
  - Playwright E2E는 엔진 파일이 없어 돌리지 못했습니다. 실기기 확인도 하지 않았습니다.
  - 보고 형식 검사(`joedesign-skill/scripts/report-check.mjs`)는 돌리지 못했습니다. 이 환경이 보고서를 파일로 쓰는 것을 막기 때문입니다. 그래서 이 보고에는 검사 통과 표시 줄이 없습니다.
- 다음 작업: 간격 값을 확인해 주세요. 작은 화면에서 판을 줄일지, 말풍선 내용을 접을지 정해 주시면 LAYOUT-05를 고친 뒤 `--strict`로 다시 검사하겠습니다.
