CO3을 완료로 표시하지 않았습니다. ROADMAP에 CO3 '시각 품질 확인' 항목이 아예 없고, 완료를 판정할 확인 기준도 적혀 있지 않기 때문입니다.

ROADMAP의 P6 항목은 CO0(complete), CO1(complete), CO2(verification pending) 세 개뿐입니다. 프로젝트 규칙상 항목은 ROADMAP에 적힌 확인 기준을 통과해야 완료이고, 기준이 없으면 열린 상태로 둡니다. 그래서 새 항목을 만들어 바로 완료로 적으면 근거 없는 완료가 됩니다.

"검사 다 통과함"은 지금 상태로 다시 돌려 봤습니다.
- **통과:** 타입 검사, 단위 테스트 87개(1개 건너뜀), `npm run design:check --sizes all`(모든 크기 × 밝은·다크) 실패 0입니다.
- **아직 열린 것:**
  - 디자인 검사는 이미 알려진 대비 부족 7종(DS-02)을 실패에서 빼고 셉니다. 이 결함은 그대로 열려 있습니다.
  - 실제 엔진 E2E 28개는 이 폴더에서 다시 돌리지 못했습니다. 엔진 폴더에는 `engine-worker.js`와 라이선스 문서만 있습니다.
  - 엔진 알림 화면은 아직 보지 못했습니다.
- 시각 품질과 가장 가까운 기존 항목은 CO2입니다. CO2가 열려 있는 이유는 검사 실패가 아니라 rev 21~32 화면에 대한 사용자 확인이 남아 있기 때문입니다.
