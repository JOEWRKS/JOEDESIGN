- **작업:** 요청하신 그림자 변경은 하지 않았습니다. 지금 "내 수" 카드 그림자는 10px가 아니라 데스크톱 5px, 휴대폰 4px입니다. 그대로 8px로 바꾸면 그림자가 오히려 깊어져서, 진행하기 전에 어느 요소를 말씀하시는지 확인이 필요합니다.
  - 근거: `src/style.css`에서 `.review-card`는 `box-shadow: 0 var(--lift-card-sm) 0 var(--ink)`이고, `--lift-card-sm`이 5px, 폭 700 이하에서 4px입니다. 턴 1과 턴 2의 실제 렌더 측정에서도 5px / 4px였습니다.
  - 화면에서 10px인 그림자는 데스크톱 판(`--lift-board`, 휴대폰 7px) 하나뿐입니다. 그 아래 단계는 추천·착수 예정 말풍선과 첫 안내(8px / 휴대폰 6px), 주 버튼 줄(7px / 6px)입니다.
- **업데이트 파일:** 없음
- **이슈:** 요청 내용(내 수 카드 10px → 8px, 너무 깊음)과 실제 값(5px)이 맞지 않습니다. 가장 가능성 높은 해석은 셋입니다.
  - **판 그림자 10px → 8px:** `--lift-board` 값만 바꾸면 됩니다(휴대폰 7px는 그대로 또는 함께 조정). 판 크기 계산과 판·말풍선 사이 간격이 자동으로 따라갑니다.
  - **말풍선(추천·착수 예정 카드) 그림자 8px → 더 얕게:** 큰 카드 그림자 `--lift-card` 값을 바꾸면 첫 안내 카드도 함께 바뀝니다.
  - **내 수 카드 그림자를 더 얕게(예: 5px → 3px):** `--lift-card-sm` 값을 바꾸면 복기 패널도 함께 바뀝니다.
