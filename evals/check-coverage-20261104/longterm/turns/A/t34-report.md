- **작업:** 디자인 검사를 약 5배 빠르게 했습니다. 전체 크기 검사가 266초에서 약 55초로, 기본 검사가 36초에서 11초로 줄었습니다.
  - **원인:** 3분이 넘던 것은 `--sizes all`(15크기 × 2테마)이었습니다. 30개 조합을 하나씩 차례로 돌려서 266초가 걸렸습니다.
  - **바꾼 것:**
    - 크기·테마 조합을 브라우저 하나에서 동시에 여러 개 돌립니다. 기본 동시 수는 CPU 수의 절반(이 PC는 6, 최대 8)이고, `--jobs N`으로 바꿀 수 있습니다.
    - 결과는 원래 순서대로 찍습니다.
    - 빌드 파일은 한 번만 읽어 함께 씁니다.
    - 검사 규칙·상태·기다리는 시간은 그대로라 검사 내용은 같습니다.
  - **결과:**

    | 실행 | 바꾸기 전 | 바꾼 뒤 |
    | --- | --- | --- |
    | 기본(2크기 × 2테마) | 36초 | 11초 (`npm run design:check`는 build 포함 15초) |
    | `--sizes all`(15크기 × 2테마) | 266초 | 54~57초 |

    - 전체 크기를 동시 실행으로 세 번 연속 돌려 모두 실패 0이었고, 결과가 흔들리지 않았습니다.
    - 일부러 옛 빌드로 돌리면 236건 실패와 종료 코드 1이 나와, 어긋남은 그대로 잡습니다.
