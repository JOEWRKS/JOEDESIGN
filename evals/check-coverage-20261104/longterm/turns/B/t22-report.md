승률 가이드 스위치를 켰을 때의 바탕색을 연두에서 파랑으로 바꿨습니다. 밝은 모드는 #2B6FF2, 다크 모드는 #5B9CFF입니다. 예전 연두는 흰 바탕과의 대비가 1.68:1이라 잘 안 보였는데, 이제 4.51:1입니다. 파랑 색값은 제가 고른 것이라 확인이 필요합니다.

  - 색 검사 스크립트(`work/design/token-audit.mjs`)의 허용 색 목록에 새 색 두 개를 추가했습니다.

- **이슈:**
  - 다크 모드에서 흰 손잡이와 파랑의 대비가 2.75:1입니다. 손잡이에 외곽선이 있어서 구분은 됩니다.
  - 같은 L-B 폴더를 다른 작업자도 동시에 고치고 있어서, 문서는 고치기 직전에 다시 읽고 필요한 줄만 넣었습니다.
- **해결:** 빌드를 임시 폴더에 따로 만들어 5399 포트에서 고정 응답 엔진으로 띄워 확인했습니다.
  - 1440×900과 390×844, 밝은·다크 두 모드 모두에서 켜짐 색이 파랑으로 바뀌었고, 꺼짐 색은 예전 그대로입니다. 스위치 높이는 44px입니다.
  - 대비는 계산으로 확인했습니다.

    | 모드 | 켜짐 색 대 바탕 | 켜짐 색 대 꺼짐 색 |
    | --- | --- | --- |
    | 밝은 | 4.51:1 | 3.04:1 |
    | 다크 | 4.94:1 | 3.16:1 |

  - 색 검사는 두 모드 모두 PASS 202 / FAIL 12입니다. 허용 색 검사는 전부 통과했습니다. FAIL은 원래 있던 글자 대비(DS-01)와 금수 ✕ 표식 대비(DS-05) 문제로, 직전 로그와 비교해 새로 생긴 FAIL은 없습니다.
  - 간격 검사 939/939, 넘침 검사 12건 중 0, 타입 검사(`tsc`)를 통과했습니다.
  - 캡처 4장을 직접 열어 확인했습니다.
