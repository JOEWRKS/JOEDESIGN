시작 화면 제목 크기는 바꾸지 않았습니다. 지금 코드와 실제 화면 어디에도 28px 제목이 없고, 32px로 맞추면 오히려 모든 화면에서 제목이 작아지기 때문입니다.

- **작업:**
  - 시작 화면 제목 "오목 한 판!"(`h1.logo`)의 크기 규칙을 확인했습니다. `src/style.css`의 `.logo` 규칙이 `clamp(40px, min(11vw, 7.5dvh), 76px)`이고, 키 720px 이하 화면은 `clamp(36px, 10vw, 56px)`입니다. 28px로 정한 곳은 없습니다.
  - 7개 화면 크기에서 실제로 표시되는 크기를 쟀습니다. 공용 `dist` 폴더는 건드리지 않으려고 임시 폴더에 따로 빌드했고, 5399 포트에서 고정 응답 엔진으로 띄웠습니다.

    | 화면 크기 | 제목 크기 |
    | --- | --- |
    | 1440×900 | 67.5px |
    | 1366×768 | 57.6px |
    | 1024×768 | 57.6px |
    | 768×1024 | 76px |
    | 390×844 | 42.9px |
    | 375×667 | 37.5px |
    | 360×640 | 36px |

  - 시작 화면의 다른 글자는 부제 20px, 출처 줄 13px, 안내문 13~15px, 선택 버튼 16~18px입니다. 이 중에도 28px는 없습니다.
- **업데이트 파일:** 없음. 질문 단계라 코드와 문서 모두 그대로 두었습니다.
- **이슈:**
  - 28px라는 값은 `DESIGN.md` 아래쪽 옛 초기 방향 표(v0.1)의 "제목 24–28px 제안"에서 온 것으로 보입니다. 지금 화면과는 맞지 않습니다.
  - 같은 L-B 폴더를 다른 작업자도 동시에 고치고 있습니다. 다크 모드, 로고 영역 축소, `src/tokens.css` 분리, DS7~DS10이 새로 생겼습니다. 오늘 로고 영역 축소 작업에서 제목 최대 크기가 96px에서 76px로 줄어든 상태이고, 이번 요청은 그 작업과 겹칩니다.
