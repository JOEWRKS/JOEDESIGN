모든 버튼의 눌림 효과를 같은 방식으로 맞췄습니다. 이제 어떤 버튼이든 누르면 그림자가 줄고 그만큼 내려가기만 하고, 버튼 면 색은 바뀌지 않습니다. 앞으로 어긋나면 잡히는 검사(S18)도 넣었습니다.

- **작업:**
  - **측정:** 화면에 보이는 모든 버튼을 강제로 눌린 상태로 만들어 그림자·내려가는 거리·버튼 면을 비교했습니다(1440×900·390×844, 시작·후보·예비 착수·새 게임 확인·끝난 판).
  - **다르던 것:**
    - "새 게임!" 같은 노란·연두 주 버튼("게임 시작!", "○○ 고르기", "○○에 두기"도 같은 버튼)은 누르면 아래쪽 음영까지 사라져서 면 색이 바뀌어 보였습니다. 다른 버튼은 내려가기만 합니다.
    - 휴대폰에서는 주 버튼에 평소에도 아래쪽 음영이 없었습니다. 연두 "○○에 두기"만 있었습니다.
    - 승률 가이드 스위치는 누를 때 눌림 효과가 없었습니다.
    - 나머지 버튼(상단 아이콘·선택·알약·되돌리기·취소·창 버튼)은 원래 맞았습니다.
  - **바꾼 것(CSS):**
    - 주 버튼의 아래쪽 음영이 평소에도, 눌러도 그대로 남게 했습니다. 휴대폰에서도 같습니다.
    - 승률 가이드 스위치에도 다른 버튼과 같은 눌림을 넣었습니다(그림자 4→1px, 3px 내려감).
  - **검사:** 토큰 검사에 눌림 규칙(S18)을 추가했습니다. 버튼마다 눌린 상태의 그림자(1px, 큰 버튼 2px), 내려가는 거리, 아래쪽 음영을 확인합니다.
