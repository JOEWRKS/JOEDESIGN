시작 화면의 로고 영역 높이를 줄이고, 휴대폰 대국 화면의 판을 키웠습니다. 판은 390×844 기준 366px에서 374px이 됐습니다. 다만 "로고 영역"을 시작 화면 제목 부분으로 해석했으니, 대국 화면 상단 줄을 말씀하신 거라면 알려 주세요.

- **작업:**
  - **해석:**
    - "로고 영역"은 로고 그림과 "오목 한 판!" 제목이 있는 시작 화면 윗부분으로 봤습니다. 휴대폰 대국 화면 상단 줄에는 로고 글자가 보이지 않기 때문입니다.
    - 390×844에서 판 크기는 화면 높이가 아니라 화면 폭에 막혀 있었습니다. 그래서 위쪽을 줄이는 것만으로는 판이 커지지 않아, 좌우 여백도 줄였습니다.
  - **로고(`src/style.css`):**
    - 로고 그림 0.72배로 축소, 키 큰 화면에서 1.3배로 키우던 것도 없앴습니다.
    - 제목 글자 최대 96 → 76px, 글자 외곽선 8 → 7px
    - 로고 영역 높이: 1440×900 264 → 217px, 768×1024 299 → 226px, 390×844 228 → 191px
  - **휴대폰 대국 화면:**
    - 좌우 여백 12 → 8px. 판·말풍선·버튼이 모두 8px 넓어집니다.
    - 상단 줄 높이 58 → 54px. 키 작은 휴대폰에서는 판 크기가 높이에 막혀 있어서, 이것으로 판이 4px 커집니다.
    - 판 크기: 390×844 366 → 374px, 430×932 406 → 414px, 375×667 279 → 283px, 360×640 252 → 256px
    - 컴퓨터와 태블릿은 그대로입니다.
  - 값은 모두 제가 정한 제안입니다.
- **업데이트 파일:**
  - 코드: `src/style.css`
  - 문서: `DESIGN.md`(로고 글자 크기, 휴대폰 상단 줄·여백), `ROADMAP.md`(P7에 DS10 추가, 현재 줄), `TASK.md`
  - 검사 기록: `work/design/logo-board-check.log`
  - 커밋하지 않았습니다.
