- **작업:**
  - **명령 하나:** `package.json`에 `design:check`를 넣었고, 실행기는 `work/design/check.mjs`입니다.
  - **하는 일:**
    1. 운영 빌드를 만들고, 미리보기 서버를 `GOMOKU_DEV_PORT` 포트(기본 5199)에 띄웁니다.
    2. 다섯 검사를 동시에 돌립니다: 토큰 검사(밝은 모드), 토큰 검사(다크 모드), 간격 검사, 복기 바 검사, 넘침 검사.
    3. 규칙별 결과를 모아 보여 주고 서버를 끕니다.
    4. 실패가 하나라도 있으면 종료 코드 1을 냅니다. 열린 결함과 이어진 실패는 "열린 결함"으로 표시만 하고, 통과로 바꾸지는 않습니다.
  - **옵션:** `npm run design:check -- --all`은 넘침 검사를 12크기로 돌리고, `-- --serial`은 검사를 하나씩 차례로 돌립니다.

  - 이 명령을 위해 손본 곳:
    - 토큰 검사가 실패하면 종료 코드 1을 내게 했습니다.
    - 토큰 검사와 복기 검사의 캡처는 저장소에 올라가지 않는 `work/design/matrix/check/` 폴더로 보내게 했습니다.
