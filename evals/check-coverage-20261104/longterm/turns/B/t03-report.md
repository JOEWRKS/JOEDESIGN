내 수 카드(`.review-card`) 그림자를 데스크톱 5px에서 4px로 줄였습니다. 요청하신 숫자와 실제 값이 달라 그림 기준 10→8로 해석해 적용했고, 이 해석이 맞는지 확인이 필요합니다.

- **작업:**
  - 실제 CSS 값을 확인해 보니 내 수 카드 그림자는 데스크톱 **5px**, 휴대폰 4px였습니다. 10px 그림자는 이 카드가 아니라 **판**에 있습니다.
  - 제가 만든 캡처는 2배 밀도라서, 데스크톱 5px이 그림 위에서는 10px로 보입니다. 그래서 "그림에서 10 → 8"로 해석했습니다.
  - CSS 값을 8px로 바꾸면 오히려 그림자가 깊어져 "너무 깊다"는 뜻과 반대가 됩니다.
  - 그래서 데스크톱을 5px → 4px로 줄였습니다(줄이는 비율 10→8과 같음). 휴대폰은 이미 4px(그림에서 8px)라 그대로 두었습니다. 이제 두 크기 모두 4px입니다.
  - 카드 아래 간격 보정 값도 5px → 4px로 맞췄습니다. CSS만 바꿨습니다.
- **업데이트 파일:**

  - 기록: `DESIGN.md`(그림자 단계 E2 줄, 토큰 역할 1행), `ROADMAP.md`(DS2 근거 칸), `TASK.md`(2026-11-04 그림자 항목)
