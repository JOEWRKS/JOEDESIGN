대국 화면(말풍선·버튼 영역을 같이 쓰는 시작 화면 포함)의 간격을 규칙 하나로 맞추고 코드에 반영했습니다. 새 검사 스크립트로 7개 화면 크기 × 7개 상태를 재면 529건 모두 통과합니다. 같은 검사를 바꾸기 전 코드에 돌리면 325건이 실패해서, 검사가 기존 어긋남을 실제로 잡는 것도 확인했습니다. 다만 간격 값은 제가 정한 제안이라 화면을 보고 확인해 주셔야 합니다.

- **작업:**
  - 원인은 같은 12px 간격을 위 카드의 아래 그림자(3~8px)가 먹은 것이었습니다. 그래서 보이는 간격이 1~9px로 제각각이었습니다. 버튼 줄과 그 아래 안내 줄 사이는 1px뿐이었습니다.
  - 그래서 간격을 그림자까지 포함한 보이는 경계 기준으로 정했습니다(SP1~SP6, 4px 단계):

    | 간격 | 컴퓨터 | 휴대폰 |
    | --- | --- | --- |
    | 판 → 말풍선 묶음 | 16px | 12px |
    | 카드 사이, 버튼 영역 줄 사이 | 12px | 8px |
    | 한 줄의 버튼 사이 | 12px | 8px |
    | 카드 안 묶음 사이 | 8px | 6px |
    | 묶음 안(큰 숫자 → 부제, 제목 → 설명) | 4px | 2px |
    | 큰 카드 안쪽 여백 | 16·20px | 12·14px |
    | 작은 카드 안쪽 여백 | 10·16px | 8·12px |

  - `src/style.css` 끝에 간격 블록 37줄을 넣었습니다. 각 카드는 자기 그림자 높이만큼 아래 여백을 더 받고, 말풍선은 숨은 요소가 빈 간격을 만들지 않게 세로 정렬 방식을 바꿨습니다. 배치와 판 크기 계산은 그대로입니다.
  - 새 검사 `work/design/spacing-check.mjs`는 위 간격을 허용 ±1px로 재고, 하나라도 어긋나면 종료 코드 1로 끝납니다.
