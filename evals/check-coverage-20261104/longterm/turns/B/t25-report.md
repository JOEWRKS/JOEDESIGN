E2E가 이제 기본으로 데스크톱(1440×900) 프로젝트만 돕니다(15개 테스트). 휴대폰 프로젝트는 지우지 않고, 환경변수 `GOMOKU_E2E_MOBILE=1`을 주면 함께 돌게 남겼습니다(이때 30개). 다만 BRIEF가 휴대폰 직접 조작을 요구해서, 기본 실행에서는 그 확인이 빠진다는 점을 알려 드립니다.

- **작업:**
  - `playwright.config.ts`: 기본은 데스크톱 프로젝트만 돌고, `GOMOKU_E2E_MOBILE=1`일 때만 휴대폰 프로젝트(390×844, 터치)를 추가합니다.
  - README의 E2E 설명과 ROADMAP 복기 바 항목(RPL4)의 판정 문구를 이에 맞게 고쳤습니다.
- **업데이트 파일:** `playwright.config.ts`, `README.md`, `ROADMAP.md`, `TASK.md`. 커밋하지 않았습니다.
- **이슈:**
  - BRIEF는 휴대폰 390×844 직접 조작을 요구합니다. ROADMAP의 화면 조작(U2)·실제 브라우저 확인(V2)·복기 항목도 두 크기 E2E를 근거로 삼아 왔습니다.
  - 기본 실행에서는 휴대폰 터치로 두고, 확정하고, 되돌리고, 복기하고, 금수를 누르는 흐름을 E2E로 다시 확인하지 않게 됩니다.
  - 휴대폰 근거로 남는 것: `npm run design:check`의 간격·복기 검사는 390×844·375×667·360×640에서 터치로 대국과 복기를 실제로 조작합니다. 다만 가짜 엔진을 써서 엔진 동작까지 확인하지는 않습니다.
- **해결:**
  - `npx playwright test --list`로 테스트 목록을 확인했습니다. 기본 15개(데스크톱), `GOMOKU_E2E_MOBILE=1`일 때 30개입니다.
  - 타입 검사(tsc)는 통과했습니다.
- **남은 문제:**
  - E2E 실제 실행은 여전히 엔진 파일이 없어 못 합니다(ENV-05).
  - 이전 턴부터 열린 것: DS-01·DS-03·DS-04·DS-05, ENV-05와 그에 걸린 DS-02 종료, 사용자 확인 항목들, CO2
