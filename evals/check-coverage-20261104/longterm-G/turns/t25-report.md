E2E 기본 실행을 데스크톱(1440×900)만 돌도록 바꿨습니다. 모바일 프로젝트는 지우지 않았고, `GOMOKU_E2E_MOBILE=1`을 설정하면 다시 함께 돕니다.

- **작업:**
  - `playwright.config.ts`: 기본 프로젝트를 데스크톱 하나로 줄였습니다. 모바일(390×844 터치)은 위 환경변수를 켤 때만 추가됩니다.
  - `README.md`: 검사 대상 설명을 이에 맞게 고쳤습니다.
  - 확인한 것: `npx playwright test --list`로 보면 기본은 15개(데스크톱), 환경변수를 켜면 30개입니다. `tsc`도 통과했습니다.
  - E2E를 실제로 돌리지는 못했습니다. 이 폴더에 Playwright 브라우저가 설치돼 있지 않아서입니다(ENV-06).
- **업데이트 파일:** `playwright.config.ts`, `README.md`, `TASK.md`(ds21), `ROADMAP.md`(현재 줄). 커밋은 하지 않았습니다.
- **이슈:** 기본 E2E에서 휴대폰 동작 검사가 빠집니다. 빠지는 것은 탭 두 번으로 착수하기, 첫 안내 건너뛰기 탭, 360×640에서 판 칸 숫자 표시(AC-014) 같은 휴대폰 전용 흐름입니다. 휴대폰 화면 배치·버튼 크기·간격은 `npm run design:check`가 390×844에서 계속 재지만, 터치 동작 흐름은 재지 않습니다.
