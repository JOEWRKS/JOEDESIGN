도움말 창을 말풍선 카드와 같은 모양으로 맞췄습니다. 이제 테두리·모서리·안쪽 여백·제목 크기가 말풍선과 같고, 12크기 모두에서 창이 화면 안에 스크롤 없이 들어갑니다.

- **작업:**
  - 기준은 대국 화면의 말풍선 카드로 잡았습니다. 데스크톱 기준 차이는 다음과 같았습니다.

    | 항목 | 바꾸기 전 도움말 창 | 말풍선(= 바꾼 뒤 도움말 창) |
    | --- | --- | --- |
    | 모서리 | 24px | 26px |
    | 안쪽 여백 | 24px | 16·22·18px |
    | 제목 크기 | 26px | 22px |
    | 휴대폰 테두리 | 4px | 3px |

  - 말풍선 값을 `src/tokens.css`의 카드 모양 토큰으로 옮겼고, 말풍선과 도움말 창이 같은 토큰을 씁니다. 말풍선 자체 모양은 바뀌지 않았습니다.
  - 창 안의 메모 상자(숫자의 뜻, 엔진 라이선스)는 "내 수 카드"와 같은 모서리(20 / 16px)로 맞췄습니다.
  - 카드 라벨("도움말"), 닫기 버튼, 노란 "조작 안내 다시 보기" 버튼은 그대로 뒀습니다.
  - `system-check`에 R14를 넣었습니다. 열린 도움말 창의 모양이 카드 토큰과 다르면 실패합니다.
- **결과:**
  - R14는 12크기에서 24/24, 다크 모드 4/4입니다.
  - 나머지 디자인 검사도 그대로입니다. 남은 실패는 기존 대비 미달(R8·R8B, A11Y-05)뿐입니다.
  - 바꾸기 전후 캡처를 남겼습니다: `work/design/shots/ds14-before-*.png`, `ds14-after-*.png`.
  - R14를 처음 만들 때는 말풍선과 직접 비교했더니 768×1024·820×1180에서 실패했습니다. 이 크기에서는 말풍선이 낮은 칸에 맞춰 줄어들기 때문이라, 비교 기준을 카드 토큰으로 고쳤습니다.

  - 코드: `src/tokens.css`, `src/style.css`, `work/design/system-check.mjs`
  - 기록: `DESIGN.md`(카드 모양 토큰 행, 화면 규칙과 검사 표의 R14), `TASK.md`(ds22), `ROADMAP.md`(DS13)
