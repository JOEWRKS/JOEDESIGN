간격 규칙을 정해 DESIGN.md에 적고 `src/style.css`를 거기에 맞췄습니다. 다시 어긋나지 않게 잡는 검사 스크립트도 추가했습니다. 다만 브라우저를 쓸 수 없어 실제 화면에서 간격을 재 보지는 못했습니다. 그래서 이 결함은 아직 열어 둡니다.

- **작업:**
  - **원인:** 카드와 버튼 아래의 입체 그림자(3~10px)가 레이아웃에서 자리를 차지하지 않습니다. 그래서 같은 간격 값을 줘도 위 블록 그림자가 깊을수록 실제로 보이는 틈이 좁아졌습니다.
    - 버튼 줄과 승률 가이드 사이: 약 1px
    - 카드 사이: 약 7px
    - 세로 배치에서 판과 말풍선 사이: 2~5px
    - 그 밖에 안내 줄에만 margin 8px이 따로 붙어 있었고, 휴대폰은 간격 값이 8·10·12px로 섞여 있었습니다. 착수 예정 상태에서는 되돌리기 버튼 폭이 줄어들었습니다.
  - **규칙(DESIGN.md "간격 규칙 — 메인 화면"):**
    - 간격 값은 4px 단위 5단계만 씁니다.
    - 블록 사이 간격은 12px, 휴대폰과 낮은 화면은 8px입니다.
    - 큰 버튼 사이는 12px, 좁으면 8px입니다.
    - 작은 버튼 묶음 안은 8px입니다.
    - 시작 화면의 제목·선택 카드·시작 버튼 사이는 16px, 낮은 화면은 8px입니다.
    - 그림자 깊이를 블록의 자리에 넣어서, 눈에 보이는 간격이 설정한 간격 값과 같아지게 했습니다.
    - 블록마다 따로 붙이는 위아래 바깥 여백은 쓰지 않습니다.
  - **검사:** 새 검사 스크립트는 DESIGN.md의 표와 CSS·화면 틀 코드를 비교합니다. 현재 코드는 129개 항목 모두 통과합니다. 변경 전 CSS에 돌리면 107건이 실패해, 검사가 예전 불일치를 실제로 잡는 것을 확인했습니다. `npx tsc --noEmit`도 통과했고, `npx vitest run`은 95개 통과·1개 건너뜀입니다(엔진 파일이 없어 건너뛰는 기존 검사).
- **업데이트 파일:** `src/style.css`, `DESIGN.md`, `work/design/spacing-check.mjs`(+ `spacing-check.d.mts`), `tests/unit/spacing.test.ts`, `package.json`(`npm run check:spacing`), `TASK.md`, `ISSUES.md`, `ROADMAP.md`. `src/main.ts`는 바꾸지 않았고, 커밋도 하지 않았습니다.
- **이슈:** UI-05(메인 화면 간격 불일치)를 새로 열었습니다. 닫는 조건은 실제 화면에서 간격을 재 확인하는 것과 사용자 확인입니다.
- **해결:** 재발 검사 스크립트는 동작을 확인했습니다. 일부러 규칙을 어긴 경우 7종을 넣어 보니 모두 실패로 잡았습니다. 간격 수정 자체는 화면에서 재 보지 못해 아직 해결로 보지 않습니다.
- **남은 문제:**
  - 실제 화면 간격, 넘침, 말풍선 접힘은 측정하지 못했습니다(UNVERIFIED). 12개 화면 크기 검사와 E2E 테스트도 돌리지 못했습니다.
  - 독립 검토(전문가 리뷰, 새 시각으로 보는 비평)는 하지 않았습니다.
  - 적힌 값은 제가 고른 제안이라 사용자 확인 전입니다.
  - 계산상 세로 태블릿(768×1024)에서는 판이 508px에서 483px로 작아집니다. 휴대폰 390×844 판은 그대로입니다.
