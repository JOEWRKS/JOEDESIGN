간격 규칙을 정해 DESIGN.md에 적었고 src/style.css를 거기에 맞췄으며, 검사 스크립트 `work/design/spacing-check.mjs`를 추가했습니다. 브라우저를 쓸 수 없어서 코드에 적힌 값으로만 확인했습니다. 실제 화면에서 간격을 재지 못했으므로 문제(DESIGN-05)는 열어 두었습니다.

간격이 제각각이었던 원인은 카드와 버튼 아래의 입체 그림자가 간격 안으로 들어와 간격을 먹은 데 있었습니다. 그래서 실제로 보이는 간격이 1~9px로 달랐습니다. 착수 버튼과 그 아래 안내 줄은 1~2px까지 붙어 있었고, 판과 말풍선 사이는 6px였습니다. 금수 안내만 16px였고, 한 줄 안 버튼 간격은 12·10·8·6px가 섞여 있었습니다.

- **작업:**
  - 간격을 "눈에 보이는 가장자리 사이 거리(그림자 포함)"로 정했습니다.
  - 값은 넓은 화면/휴대폰 순서로 이렇게 정했습니다(제가 정한 값이고 아직 승인받지 않았습니다):

    | 쓰임 | 넓은 화면 | 휴대폰 |
    | --- | --- | --- |
    | 카드·안내 줄 사이 | 12px | 8px |
    | 판↔패널, 패널↔버튼 영역 | 16px | 12px |
    | 한 줄 안 버튼 사이 | 10px | 8px |
    | 패널이 아주 낮을 때 | 4px | 4px |

  - 그림자 깊이를 그림자와 아래 여백에 같은 값으로 써서, 설정한 간격이 화면에 보이는 간격과 같아지게 했습니다.
  - 검사 스크립트는 DESIGN.md 값과 CSS 값이 같은지, 간격에 px 숫자를 직접 쓰지 않았는지, 따로 준 여백이 없는지, 그림자 보정이 있는지를 봅니다. 위반이 있으면 종료 코드 1로 끝납니다.
- **업데이트 파일:** src/style.css, DESIGN.md("간격 규칙 — 제안 v1" 절), work/design/spacing-check.mjs(새 파일), ROADMAP.md(CO3 추가, 현재·다음 줄 다시 씀), TASK.md(2026-11-07 기록), ISSUES.md(DESIGN-05). 커밋은 하지 않았습니다.
- **이슈:**
  - DESIGN-05(간격 불일치)는 렌더 확인 전이라 open입니다.
  - 패널은 높이가 고정되어 있고 넘치는 부분을 숨깁니다. 이번 수정으로 블록 아래 여백이 그림자만큼 늘어서 패널 맨 아래 블록이 몇 px 잘릴 수 있습니다. 아직 확인하지 못했습니다.
  - 화면이 조금 달라지는 곳이 하나 있습니다. 휴대폰에서 보조 '두기' 버튼, 초록 두기 버튼, 비활성 버튼의 그림자가 줄의 다른 버튼과 같은 6px가 됩니다(전에는 7px).
- **해결:** 없음. 수정은 `changed` 상태이고, 화면에서 직접 확인하지 않아 `fixed`로 보지 않습니다.
- **남은 문제:**
  - 1440×900·390×844에서 렌더 간격을 직접 재지 못했습니다. 그래서 DESIGN.md 간격 규칙 표의 모든 행이 "not spot-checked"입니다.
  - 12크기×6상태 넘침·잘림 검사도 다시 돌리지 못했습니다.
  - 규칙에 넣지 않은 부분: 카드 안쪽 리듬, 시작 화면 선택 줄 사이, 도움말 창, 새 게임 확인 창. 후보 알약이 두 줄로 넘어가면 둘째 줄 간격은 약 6px로 보일 수 있습니다.
  - 질문: 간격 값(12/8, 16/12, 10/8)을 이대로 둘까요?
- **다음 작업:** 브라우저를 쓸 수 있는 세션에서 두 크기의 간격을 직접 재서 표의 Spot check 칸을 채우고, `work/design/capture-matrix.mjs`로 넘침·잘림을 다시 확인합니다. 그다음 간격 값을 확인받습니다.
