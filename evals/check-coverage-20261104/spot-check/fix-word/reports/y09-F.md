메인 화면(시작 화면과 대국 화면)에 간격 규칙 S1~S5를 정해 코드에 맞췄고, 검사 스크립트를 넣었습니다. 지금은 spacing 1150/1150 (12크기×8상태, 렌더; 표본 대조 S1~S4는 일치, S5는 대조 안 함)입니다. 원래 화면을 같은 스크립트로 재면 420/1163이었습니다. 규칙 값은 제가 정한 제안이고, 시각 확인은 아직 받지 않았습니다. 커밋은 하지 않았습니다.

- **작업**
  - 원인: 카드와 버튼 아래 그림자(3~10px)를 빼지 않고 CSS 간격을 곳곳에 따로 줘서, 실제로 보이는 틈이 1~20px로 흩어져 있었습니다. 예를 들어 1440×900에서 말풍선→후보 알약이 4px, 버튼 줄→아래 안내 줄이 1px이었습니다.
  - 규칙: 그림자까지 포함해 보이는 가장자리 기준으로 쟀습니다. 토큰은 4·8·12·16·20px입니다. 앞 값은 보통 화면, 뒤 값은 폭이나 높이가 700px 이하인 작은 화면입니다.
    - S1 블록 사이 12/8
    - S2 판→말풍선 칸, 말풍선 칸→버튼 칸 16/12
    - S3 버튼 줄 안: 큰 버튼 12, 작은 버튼 8
    - S4 카드 안쪽 여백: 주 말풍선 16/20, 보조 카드 12/16, 안내 알약 4/12
    - S5 카드 안: 부분 사이 8, 제목→본문 같은 짝 4
  - 코드: `src/style.css` 끝에 간격 구역을 하나 만들었습니다. 그림자 깊이만큼 아래 여백을 주는 방식이라, 새 블록을 넣을 때 그림자 깊이만 적으면 됩니다. 흩어져 있던 여백 값과 쓰지 않는 `data-detail` 규칙은 지웠습니다. 보조 카드 셋의 그림자도 5/4px로 맞췄습니다(첫 안내 카드는 7px이었음).
  - 검사: `work/design/spacing-check.mjs`를 추가했습니다. 엔진 파일 없이 합성 엔진(`work/design/fake-engine-worker.js`)으로 화면 상태를 만듭니다. 규칙 값은 CSS에서 읽지 않고 스크립트에 따로 적어 두어, CSS가 어긋나면 실패합니다. 실패가 있으면 종료 코드 1로 끝나고, 넘침 검사도 함께 돌립니다.
    - 실행: `npx vite build` → `npx vite preview --host 127.0.0.1 --port <p> --strictPort` → `GOMOKU_DEV_PORT=<p> node work/design/spacing-check.mjs`

- **이슈**
  - 원래 화면에서 복기 말풍선이 489×866, 375×667, 360×640에서 칸 밖으로 잘려 있었습니다(넘침 93/96).
  - 간격을 맞추자 375×667, 360×640의 후보 화면과 첫 안내 화면이 칸을 넘쳤습니다. 낮은 칸에서 덜 중요한 줄을 접는 방식으로 막았습니다.

- **해결**
  - 간격 틈 고침: spacing 1150/1150 (12크기×8상태, 렌더). 캡처 픽셀과 직접 대조한 결과:
    - 1440×900 말풍선→후보 알약 4px에서 12px로(검사 12 / 관찰 12)
    - 버튼 줄→승률 가이드 스위치 1px에서 12px로(검사 12 / 관찰 12)
    - 390×844 판→말풍선 12px(검사 12 / 관찰 12), 후보 알약 사이 8px, 말풍선 안쪽 왼쪽 20px·위 16px도 검사와 관찰이 같음
  - 복기 말풍선 잘림 고침: overflow 96/96 (12크기×8상태, 렌더). 375×667 캡처에서 이전에는 말풍선 아래 테두리가 없었고, 이후에는 아래 테두리와 그림자 9px가 보입니다.
  - `tsc` 통과, 단위 테스트 87개 통과·1개 건너뜀(88개 중).

- **남은 문제**
  - 규칙 값과 아래 접기 선택은 제가 정한 것이라 사용자 확인이 필요합니다.
    - 복기 중 칸이 낮으면 말풍선 라벨·해설 기준 줄을 접고, 더 낮으면 결과 줄(흑 승리·총 수)도 접습니다.
    - 190px 이하 칸에서는 내 차례 말풍선 라벨(추천·착수 예정)을 접고, 첫 안내 버튼을 34px로 낮춥니다.
  - S5(카드 안 줄 간격)는 표본 대조를 하지 않았습니다. 이 검사는 글자 줄 높이를 포함한 요소 상자를 재는데, 캡처에서는 글자 모양만 보여 직접 맞춰 볼 수 없습니다.
  - 금수 안내, 엔진 알림, 간이 분석 상태는 합성 엔진으로 만들지 못해 간격을 재지 않았습니다.
  - E2E는 돌리지 않았습니다. 이 폴더에 엔진 파일이 없어 실제 대국을 띄울 수 없습니다.
  - 도움말 창과 새 게임 확인 창은 범위에서 뺐습니다.
