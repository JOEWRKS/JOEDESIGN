메인 화면 간격 규칙을 정해 DESIGN.md에 적었고, src/style.css를 그 규칙에 맞췄고, 검사 스크립트 `work/design/spacing-check.mjs`를 추가했습니다. 다만 모두 코드로만 확인했고 실제 화면에서는 아무것도 재보지 못했습니다(이 세션은 브라우저 실행 권한이 없음).

**간격이 어긋난 이유:** 카드와 버튼 사이 간격 값은 고정인데, 블록마다 아래로 떨어지는 그림자 깊이가 3~8px로 달라서 그 간격을 먹고 있었습니다. 코드로 계산한 보이는 간격(그림자 끝 → 다음 테두리)은 1~16px로 제각각이었습니다.
- 말풍선 카드 아래 4px, 내 수 평가 카드 아래 7px
- 큰 버튼 아래 안내 줄까지 1px(휴대폰 2px)
- 금수 안내 아래 16px
- 버튼 줄 가로 간격은 8·10·12px가 섞여 있었음

**정한 규칙(제안 값, 승인 전):**

| 쓰임 | 넓은 화면 | 좁은 화면 |
| --- | --- | --- |
| 카드·버튼 줄·안내 줄 사이(세로) | 12px | 8px |
| 같은 줄 버튼 사이(가로) | 10px | 8px |
| 줄바꿈된 버튼 사이 | 4px | 2px |
| 시작 화면 제목·카드·버튼 사이 | 18px | 10px |

좁은 화면은 폭 700 이하나 높이 700 이하입니다(시작 화면 값만 높이 720 이하 기준). 토큰은 `--space-block`, `--space-inline`, `--space-tight`, `--space-section`입니다. 공간이 빠듯한 곳 두 군데는 예외로 표에 적었습니다(후보 알약 줄 6px, 좁은 칸의 버튼 줄 8px).

**src에서 바꾼 것:**
- 블록마다 그림자 깊이를 `--drop` 하나로 정하고, 그 값을 그림자와 아래 여백에 같이 씁니다. 그래서 그림자 깊이와 상관없이 보이는 간격이 항상 위 값과 같습니다.
- 블록마다 따로 준 여백과 말풍선 칸 위아래 안쪽 여백을 없앴습니다.
- 내용이 모두 숨은 빈 안내 줄(`.foot`)은 자리를 차지하지 않게 했습니다. 그래서 시작 화면 버튼 아래 빈 공간이 없어지고, 화면이 조금 다시 가운데로 맞춰집니다.
- 직접 정한 작은 변화: 취소 버튼 그림자를 같은 줄의 다른 버튼과 맞췄습니다(5px → 7/6px).
