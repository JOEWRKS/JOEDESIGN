카드와 버튼 줄 사이 세로 간격을 기본 16px, 좁은 화면 12px로 키웠고, 검사 스크립트 기대값도 같이 맞췄습니다. 검사는 918건 모두 통과했습니다. 다만 화면이 768px 높이인 노트북(1366×768, 1024×768)에서 "직전 내 수" 카드가 사라집니다. 이걸 그대로 둘지 정해 주셔야 합니다.

- **작업:** 간격 값 하나(`--space-stack`)를 기본 12→16, 좁은 화면(폭이나 높이 700px 이하) 8→12로 바꿨습니다. 같은 값을 쓰는 곳도 함께 커졌습니다: 휴대폰에서 판과 말풍선 사이, 시작 화면 카드와 시작 버튼 사이. 시작 화면 제목과 카드 사이(24/12px)는 그대로입니다. 검사 스크립트의 기대값도 16/12로 바꿨습니다. 커밋은 하지 않았습니다.
- **업데이트 파일:** `src/style.css`, `work/design/spacing-check.mjs`, `DESIGN.md`(간격 값 표와 검사 설명), `TASK.md`(2026-11-06 항목), `ROADMAP.md`(현재·다음 작업과 CO2 줄), 새 검사 기록 `work/design/spacing-v2.log`.
- **이슈:** 간격이 넓어진 만큼 말풍선 영역이 낮아져서, 높이가 일정 값 아래면 내용을 숨기는 기존 규칙에 걸렸습니다.
  - 1366×768·1024×768: 영역 높이가 526→518px가 되어 520px 기준 아래로 내려갔고, 직전 내 수 평가 카드가 사라집니다.
  - 489×866 되돌리기 안내 상태: 197→181px가 되어 190px 기준 아래로 내려갔고, 말풍선 제목이 사라집니다.
  - 검사 스크립트는 보이는 요소만 재기 때문에 실패로 잡지 못합니다. 측정 건수만 944→918로 줄었고, 이전 CSS와 항목별로 비교해서 찾았습니다.
- **해결:** 간격 검사 918/918 통과(12개 크기 × 6개 상태, 스크롤·가로 넘침 없음), 타입 검사 통과, 단위 테스트 87개 통과·1개 건너뜀. 1440×900·1366×768·390×844 캡처를 눈으로 확인했습니다. 제가 띄운 미리보기 서버(5621)는 껐습니다.
- **남은 문제:**
  - 위의 카드·제목이 숨는 것을 그대로 둘지는 결정이 필요합니다. 숨김 기준값은 바꾸지 않았습니다.
  - 브라우저 자동 테스트(E2E)는 엔진 파일이 없어 돌리지 못했습니다.
  - 기존 넘침 검사(`capture-matrix.mjs`)는 다시 돌리지 않았습니다. 간격 검사의 스크롤·넘침 항목으로 대신했습니다.
