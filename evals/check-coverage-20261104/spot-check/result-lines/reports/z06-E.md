메인 화면 간격이 제각각이었던 원인을 CSS에서 찾았습니다. 그 원인에 맞춰 간격 규칙을 정해 `DESIGN.md`에 적었고(DRAFT, 승인 전), `src/style.css`를 맞추고 검사 스크립트 `work/design/spacing-check.mjs`를 추가했습니다. 확인은 코드에서만 했고 실제 화면에서는 아직 보지 못했습니다. 그래서 간격이 고르게 보이는지는 브라우저를 쓸 수 있을 때 확인해야 합니다.

**원인:** 카드와 버튼은 아래로 3~8px 떨어지는 입체 그림자를 가지고 있습니다. 이 그림자가 블록 사이 간격 안으로 들어가서, 같은 12px 간격인데도 말풍선 아래는 4px, 내 수 카드 아래는 7px처럼 보였습니다. 버튼과 바로 아래 안내 줄 사이는 1px뿐이었고, 금수 안내 줄 아래는 16px였습니다. 카드 안쪽 여백도 카드마다 달랐습니다.

- **작업:**
  - **규칙(DESIGN.md "간격 규칙"):** 간격은 4px 단위만 씁니다. 블록 사이에 보이는 간격(그림자 끝에서 다음 테두리까지)은 데스크톱 12px, 휴대폰과 낮은 화면 8px로 통일합니다. 한 줄 안의 버튼·알약 사이는 8px입니다. 카드 안쪽 여백은 주 카드·보조 카드·안내 줄 세 등급으로 나누고, 카드 안 세로 간격은 8px과 4px 두 가지로 정했습니다.
  - **구현:** 각 블록이 자기 그림자 깊이만큼 아래 여백을 잡게 해서, 그림자 두께와 상관없이 보이는 간격이 같아지게 했습니다.
  - **화면에서 달라지는 점(코드로 계산한 값):**
    - 카드·줄 사이가 12px(휴대폰 8px)로 고르게 벌어집니다.
    - 시작 화면에서 카드 → 시작 버튼 간격이 20 → 12px로 줄어듭니다.
    - 취소 버튼 그림자를 같은 줄의 다른 버튼과 맞췄습니다(5 → 7px).
    - 안내 줄이 비면 빈 44px 칸을 남기지 않습니다.
    - 버튼 영역 높이 예약값을 실제 높이에 맞춰서, 세로로 긴 태블릿(768×1024, 820×1180)에서 판이 12px 작아집니다.
  - **정리:** 앱에서 쓰지 않던 CSS 규칙(`.branch*`, `data-detail`, `.alt-title`)을 지웠습니다. `src/main.ts`와 테스트에서 쓰이지 않는 것을 확인했습니다.
  - **"메인 화면"의 범위:** 시작 화면과 대국 화면 둘 다로 해석했습니다. 도움말 창과 새 게임 확인 창은 뺐습니다.
- **업데이트 파일:** `src/style.css`, `DESIGN.md`(간격 규칙 섹션, 토큰 역할 표, 규칙별 검사 범위 표), `work/design/spacing-check.mjs`(새 파일), `ROADMAP.md`(P6에 CO3 항목 추가, 현재·다음 줄 다시 씀), `TASK.md`(2026-11-06 기록).
- **이슈:** 기존 화면 근거(E2E 28/28, 12크기 넘침 0)는 바뀌기 전 CSS 기준이라 지금 CSS에 대해서는 낡았습니다. 이 사실을 ROADMAP 현재 줄에 적었습니다.
- **해결:** 아래 결과는 모두 코드 기준이고, 실제 화면과 대조하지 않았습니다.

  ```
  spacing S0 4px 단계 | 429/429 | 12 sizes x 2 phases(시작·대국) | code | not spot-checked
  spacing S1 블록 사이 보이는 간격 | 369/369 | 12 sizes x 2 phases | code | not spot-checked
  spacing S2 줄 안 간격 | 85/85 | 12 sizes x 2 phases | code | not spot-checked
  spacing S3 카드 안쪽 여백 | 8/8 | 12 sizes x 2 phases | code | not spot-checked
  spacing S4 카드 안 세로 간격 | 11/11 | 12 sizes x 2 phases | code | not spot-checked
  음성 시험 | 변경 전 CSS와 일부러 어긋낸 변형 5개 모두 해당 검사 실패 | code | not spot-checked
  ```

  `npx tsc --noEmit`는 통과했습니다. `npx vitest run`은 87개 통과, 1개 건너뜀입니다. 건너뛴 1개는 엔진 파일이 없어서 자동으로 빠지는 테스트이고 CSS와는 상관없습니다.
- **남은 문제:**
  - 실제 화면에서 간격을 재지 못했습니다. 그래서 위 다섯 줄 모두 spot check를 못 했습니다.
  - 12크기 넘침 검사(`capture-matrix.mjs`)와 Playwright E2E는 다시 돌리지 않았습니다.
  - 말풍선 영역이 낮을 때 내용을 접는 단계(컨테이너 쿼리)는 검사가 값을 풀지 못합니다. 주요 크기에서 이전과 같은 단계에 머물도록 손으로 계산해 맞췄지만 화면 확인 전입니다.
  - 사용자 시각 확인이 없어 규칙은 DRAFT·proposed 상태입니다.
