메인 화면 간격 규칙(S1~S4)을 정해 `src/style.css`에 반영했고, 다시 어긋나면 실패하는 검사 `npm run check:spacing`을 추가했습니다. 12개 화면 크기 × 9개 상태(108화면)를 실제로 렌더해서 재 보니 전부 규칙대로 나왔고 넘침·잘림도 없습니다. 다만 값은 제가 정한 제안이라 사용자 확인이 필요합니다.

**어긋났던 원인:** 카드와 버튼 아래로 떨어지는 그림자가 간격을 먹고 있었습니다. CSS에는 12px로 적혀 있어도 눈으로는 카드 사이가 4~7px, 큰 버튼 줄과 바닥 안내 줄 사이가 1px로 보였습니다. 이제 간격은 그림자까지 포함한 보이는 가장자리끼리 잽니다.

**정한 규칙** (4px 단위)
- **블록 사이:** 카드, 알약 줄, 안내 줄, 버튼 줄, 바닥 줄 사이는 12px입니다. 화면 높이가 700px 이하면 8px입니다. 시작 화면의 제목→카드→시작 버튼은 20px(높이 720px 이하면 12px)입니다.
- **버튼 사이:** 큰 버튼 줄은 12px, 작은 버튼과 알약은 8px입니다. 같은 줄 큰 버튼은 높이와 그림자를 맞췄습니다.
- **카드 안쪽 여백:** 말풍선은 위아래 16 / 왼쪽 20px(폭 700px 이하 12/16)입니다. 보조 카드는 12/16(폭 700px 이하 8/12), 안내 줄은 8/12px입니다.
- **카드 안 줄 사이:** 묶음 사이는 8px, 좌표↔보조 줄과 제목↔본문은 4px입니다.

**같이 고친 기존 결함** (검사를 처음 돌려서 나왔습니다)
- 키 작은 화면(489×866·375×667·360×640)에서 되돌리기 안내, 금수 안내, 복기 상태일 때 말풍선 칸이 잘렸습니다(7화면). 이전 12크기 검사에는 이 상태들이 없어서 안 잡혔습니다.
- 1440×900에서 착수 예정일 때 되돌리기 버튼 폭이 38px로 눌렸습니다.

잘림을 없애려고 키 작은 화면에서 접는 동작 세 가지를 제가 골라 넣었습니다. 사용자 확인이 필요합니다.
- 휴대폰에서 안내 줄이 떠 있는 동안 후보 알약 줄을 접습니다. 같은 후보가 판 위에 있습니다.
- 말풍선 칸이 작은 복기 화면에서 해설 카드의 라벨과 기준 문구를 접습니다. 위 복기 카드와 내용이 겹칩니다.
- 말풍선 칸이 아주 작으면 말풍선 라벨을 접습니다.
