# 요청 폼 제품 정의

Revision: rev 2, 승인 2026-11-10 (제품 책임자).

- DEC-001: 요청은 제목과 요청 내용(최대 200자)으로 보낸다.
- DEC-002: 요청 내용 칸 아래 오른쪽에 글자 수를 `현재 / 200` 형식으로 보여 준다(예: `0 / 200`, `200 / 200`). 입력할 때마다 갱신한다.
- RULE-002: 글자 수 표시는 요청 내용 칸과 시각적으로 붙어 보여야 하며, 좁은 화면(320px)에서도 가로로 넘치지 않는다.
- AC-002: 빈 칸 `0 / 200`, 199자 `199 / 200`, 200자 `200 / 200`.
