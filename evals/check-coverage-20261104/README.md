## 배경

AI 오목 세션(2026-11-02)의 보고를 취합한 결과, 디자인 규칙 위반은 규칙이 없어서가 아니라
검사 스크립트가 한 배치·한 크기만 재면서 "0 violations"가 규칙 전체의 통과로 기록되는
데서 생겼다. JOENESS 1.3.0은 Check 기록 측에서 이를 막는다(검사 범위 명시). JOEDESIGN은
DESIGN.md 자체에 규칙→검사→배치·크기·상태→미측정 표를 두어 검사 범위가 설계 문서에
남도록 한다. 코드에서 읽은 값을 승인값처럼 적는 문제는 행 단위 상태 열로 다룬다.
