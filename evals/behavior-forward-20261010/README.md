isolated Morrow studio tasks. The user explicitly authorized separate test

messaged or modified. There is no installation, commit, push or release in this

## Method and provenance

- `PROTOCOL.md` and the input manifest were frozen before candidate execution;
  `freeze.json` is that historical freeze event, not current execution status.
- `prepare.py` creates isolated projects and the exact package copy.
  `capture-inputs.py` renders the supplied original at 1240×900 and 390×900.
- `/root/trial_new`, `/root/trial_extension` and `/root/trial_repair` each received
  only their realistic request, sources, operating core and permitted tooling in
  a fresh context. No expected fix or grading rubric was provided.
- The parent reviewed and separately pinned source-to-criteria mappings. Actual
  R and C1 specialist agents use the same core and relevant installed skill
  sources. The independent critic receives raw sources/output, not their verdicts
  or builder conclusions. Case evidence records actual source paths/hashes,
  rendered measurements, browser actions and scoped judgments.
- `bind-direct-reviews.py` is an evaluation-only adapter of those actual saved
  judgments and cited captures. Its output explicitly identifies itself as
  direct-tool evidence, **not** a runner-produced report or authenticated host
  receipt. No verdicts, skill calls or user acceptance are manufactured.
- `audit-artifacts.py` checks pinned package/source parity, protected originals
  and frame hashes. It does not authenticate the author of an observation.

Raw inputs, candidates, screenshots and review records are retained under
`.local/behavior-forward-20261010/`. These ignored local files are not claimed to
be portable evidence in Git. The recipes, decisions, review summaries and final
hash manifest in this directory identify the observed run.

inset. Independent source review required coverage of applicable panels and
child unions. Actual original rendering also exposed the status paragraph's
16px bottom margin: the measured outer inset is 41/37, not the padding token's
24/20. The revised mapping preserves this relationship rather than weakening
the expectation to fit a guessed selector.

The extension's next baseline used prose in `source_ref`; the executable
validator rejected it. The original baseline, failed invocation and old
captures remain retained. A separately reviewed syntax-only correction uses
`DESIGN.md#...`, with all criteria, targets, inputs and authority hashes unchanged.
Fresh observations bind the new raw baseline hash. These are observed case
setup corrections, not evidence of automatic semantic baseline completeness.

The first integration input map omitted contributing routes/scripts from multi-page
journeys. Independent review required the full contributing runtime union for those
checks while retaining family-specific inputs elsewhere. Independent navigation
also found a reservation count reset. The builder introduced same-tab shared demo
state and retained correct separation of confirmed records, waitlist records and
booked capacity. Final integration review evaluates that changed build separately.
The old 108-check planning proof becomes entirely UNVERIFIED against it; see
`RUN-NOTES.md` for preserved failures and sequencing.

## Boundaries

The parent actively supplies independent criteria review and real review agents.
This does not demonstrate unattended execution or a bundled host adapter. Local
pins and reports cannot prevent bypass or authenticate approval. Headless Edge
rendering and model judgments do not establish human visual acceptance, broad
design quality gains, audible screen-reader behavior or all device widths.
Impeccable's detector used a degraded parser fallback; actual visual review and
browser checks are reported separately from that detector. Its full standalone
critique workflow was outside the bounded specialist assignment.

Earlier Python 130 PASS and historical Node 14 PASS are separate regression
evidence. They are not the behavioral outcomes of this run.
