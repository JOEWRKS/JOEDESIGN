# Execution notes and scope corrections

The protocol was frozen before results. The evaluator supplied independent
criteria review and access to actual review workers when each candidate requested
them; this is part of the observed assisted workflow, not unattended execution.
No intended bug/fix or grading rubric was supplied to the three initial builders.

## Review contexts

R and C1 used separate contexts and actual applicable skill sources. They could
continue across distinct cases; they did not replace each other's judgments.
The initial independent critic context reviewed repair, then new, then extension
proof. It received raw case evidence, not builders' or other reviewers' verdicts,
but its later turns retained its own other-case context. This is narrower than a
wholly new critic process for each case and is not concealed as such.

The new interface subsequently received a one-case fresh critic
(`/root/critic_new_fresh`), with the first reports retained. Its final selected
receipt is `final-conformance-fresh.json`. After both final C1 assignments completed,
the integrated extension received a one-case fresh critic
(`/root/critic_extension_fresh`) and selected `final-integration-conformance.json`.
The repair's first critic was already a fresh context. Final result records identify
their actual contexts. All 132 extension specialist claims have R, scoped C1 and
fresh critic judgments; final executable verification returned 249 PASS, exit 0.

For final extension C1, the completed R review is followed by two bounded parallel
assignments: J/I perspectives on 72 composition/craft claims, U/V perspectives on
60 accessibility/responsive/experience claims. This partitions the 132 claims;
none are dropped. The evaluation adapter accepts both source reports and preserves
the actual context of each row. Fresh critique remains subsequent to C1.

## Observed corrections

- Source mapping: the first extension inventory omitted applicable panel child
  coverage. Parent review required actual unions and source box inspection.
- Baseline syntax: invalid prose `source_ref` was rejected by the executable
  validator, then corrected and independently repinned without criterion changes.
- Integration: independent browser navigation found planning reservations reset
  from one to zero. Scoped proof PASS was not called whole-extension completion.
- Dependencies: the first final inventory bound a multi-page journey only to its
  final route. Parent review required all contributing entry/scripts/styles/data
  for those exact journey states. Other checks retained family-specific inputs.
- The historical 108-check planning proof was reevaluated against the integrated
  build: exit 2, all 108 UNVERIFIED. Old PASS did not survive changed inputs.

Case-level runtime and probe mistakes are retained in local evidence: unavailable
preview servers and native-select test sequencing were not reported as product
defects or successful observations. The adapter's first path binding attempt
rejected case-relative critic citations; resolving them against the case root
allowed matching only the actual cited evidence. No review verdict was changed.

The final artifact audit initially followed absolute paths from the archived
`proof-attempt1` observations into their former `proof` directory. Some files
there now belong to the later attempt. The first audit failure is retained in
`artifact-audit-first.json`. Every original frame was found byte-identical beside
its archived observation. The auditor now records both the obsolete-path mismatch
and the explicit archive relocation; original observations remain untouched and
are not rebound as current verification evidence.

The README and CHANGELOG still contained two outdated pending/not-activated
statements about earlier completed installation/GEO integration. These were
corrected by pointing to the existing operational evidence, without rerunning
installation or asking another project to work.

## Inference limits

Three small fictional tasks, all with supplied adequate originals, do not measure
unassisted reference discovery, complex production design, motion, every specialist
conflict/C2 path, calibrated aesthetic quality, or a general compliance rate.
Separate model contexts are not independent human acceptance. No user approval of
the generated screens is inferred from permission to run this evaluation.
